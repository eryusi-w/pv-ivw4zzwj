회사 홈페이지를 피그마 수준으로 만드는 스킬 (taste-skill)

#AI도구#디자인스킬#랜딩페이지#클로드코드#웹디자인#프론트엔드#오픈소스#UIUX#자동화#생산성

"회사 소개 페이지 하나 만들어줘"라고 하면 AI는 늘 같은 결과를 냅니다. 회색 배경에 흰 카드, 왼쪽 텍스트 오른쪽 이미지, 보라색 버튼. 피그마나 에이블리 같은 실제 사이트와는 거리가 멉니다.

taste-skill(tasteskill 2.5.1)은 이런 일반적인 AI 페이지를 figma.com·x.ai 수준으로 끌어올리는 디자인 스킬입니다. 페이지 종류를 먼저 분류하고 팔레트·폰트·히어로 레이아웃을 '딜링'하듯 배정한 뒤, 실제 브라우저에서 검증합니다. GitHub 스타 약 11만 개, MIT 라이선스입니다.

핵심 특징 3가지

  • 업종별 디자인 분류 — 소프트웨어·게임·테크·제품·서비스·장소 6종으로 사업을 분류해 그에 맞는 팔레트와 서체를 배정합니다.
  • 실제 자산 사용 — 스톡 사진 대신 오픈 아카이브의 실제 사진, 실제 브랜드 아이콘, 실제 제품 UI 조각을 씁니다.
  • 실제 브라우저 검증 — 헤드리스 크롬으로 1440·1024·768·390px 화면을 렌더링해 빈 비주얼·깨진 셰이더·대비 저하를 잡고, finish gate가 통과할 때까지 마무리합니다.

설치와 빠른 실행

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

npx skills CLI로 설치합니다. 요구사항은 Node 22 이상과 Chrome·Edge·Chromium 중 하나입니다(경로가 다르면 CHROME_PATH 지정). 스크립트가 설치되는 게 아니라 스킬 폴더 안의 Node 스크립트를 쓰므로 API 키도 별도 설치도 필요 없습니다.

실전 활용 시나리오

설치 후에는 에이전트에게 사이트 제작을 맡기면 스킬이 자동으로 로드됩니다. 처음부터 큰 프로젝트보다 작은 한 페이지로 시험하는 게 좋습니다.

git clone https://github.com/Leonxlnx/taste-skill.git
  • 1단계 — 에이전트에게 "카페 소개 랜딩페이지 하나 만들어줘"처럼 구체적인 브리프를 줍니다.
  • 2단계 — 스킬이 업종을 분류하고 팔레트·폰트·히어로 레이아웃 11종 중 하나를 배정합니다.
  • 3단계 — 에이전트가 starter.html을 바탕으로 페이지를 만들고, headless 크롬 체커가 화면 크기별로 검증합니다.
  • 4단계 — 게이트를 통과한 결과물을 확인하고, 마음에 안 드는 부분은 섹션 단위로 다시 지시합니다.

직접 쓰기 전 알면 좋은 점

셰이더 효과와 스크롤 연출은 소프트웨어·테크·게임 페이지에만 배정되고, 카페·호텔·쇼핑몰 같은 곳에는 사진과 타이포 중심의 절제된 구성이 나옵니다. 화려함이 목적이 아니라 업종에 맞는 절제라는 점이 이 스킬의 핵심입니다. 데스크톱 앱 버전(TasteCode)도 무료로 제공됩니다.

누구에게 필요한가

랜딩페이지·회사 소개 페이지·포트폴리오를 AI로 만들면서 결과물이 템플릿처럼 보이는 게 싫은 사람에게 맞습니다. 디자인을 코드로 설명하기보다 "분위기"로 지시하고 싶은 프리랜서·1인 사업자에게 특히 유용합니다.

정리

AI 페이지의 "일반적임"을 업종 분류·실제 자산·브라우저 검증으로 해결하는 스킬입니다. 요구사항이 가벼워서(Node 22+와 크롬 하나) 오늘 바로 한 페이지에 시험해 볼 수 있습니다.
