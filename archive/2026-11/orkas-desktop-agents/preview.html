데스크톱에서 AI 팀을 지휘하는 Orkas

#멀티에이전트#데스크톱앱#Orkas#로컬우선#AI팀#자동화#MIT#BYOK#커넥터#프로젝트관리

"에이전트한테 시키면 결과물이 나오긴 하는데, 계속 굴러가게 하려면 사람이 붙어 있어야 한다" — 이게 요즘 AI 작업의 공통 불만입니다. 프롬프트 하나에 답 하나가 아니라, 목표를 주고 며칠간 알아서 진행되는 시스템을 원하죠.

Orkas는 이 방향의 데스크톱 앱입니다. 로컬 우선(MIT 라이선스)으로 동작하는 멀티에이전트 팀으로, Commander라는 총괄이 목표를 받아 전문 에이전트들과 기존 코딩 에이전트들에게 일을 나눠 줍니다. GitHub 별 9천 개 규모의 신생이지만 야심이 큽니다.

Orkas는 무엇인가

Orkas는 "AI 어시스턴트가 아니라 AI 팀"을 표방합니다. 데스크톱 앱 안에서 Commander가 목표를 이해하고, 작업을 계획해 적절한 에이전트에게 배정합니다.

특이한 점은 이미 쓰는 코딩 에이전트를 흡수한다는 겁니다. Claude Code, Codex, OpenCode 같은 CLI 에이전트를 로컬 세션으로 띄워 함께 일하게 하고, 자체 전문 에이전트들과 한 계획 아래 묶습니다.

한 번의 채팅이 버그 수정, 변경 리뷰, 릴리즈 노트 초안까지 이어지는 구조입니다. 각 에이전트가 자기 영역을 맡고 Commander가 전체를 조율합니다.

Commander와 16개 전문 에이전트

앱에 기본 탑재된 전문 에이전트는 16개입니다. 분야별로 나뉩니다.

분야에이전트 예시
리서치DeepResearcher, SeoGeoAgent, StockAnalyser
콘텐츠·미디어ContentWriter, PptMaker, ImageStudio, VideoStudio, VoiceStudio
빌드·오피스UIDesigner, ProductDeveloper, OfficeWorker
이커머스리서치·카피·리뷰분석·매출분석·운영 5종

각 에이전트는 자기 스킬·메모리·도구를 가지고, 필요하면 Commander가 새 에이전트를 만들어 주기도 합니다. 마켓플레이스에 30개 이상의 에이전트가 더 있습니다.

계속 굴러가는 구조: 프로젝트·투두·자동화

Orkas의 핵심은 "한 번 묻고 끝"이 아니라 지속되는 작업입니다.

  • 프로젝트 — 목표·규칙·메모리·파일이 모인 단위. 새 대화가 항상 이전 맥락에서 시작합니다
  • 투두 + Auto-advance — 작업을 할 일로 쪼개고, Auto-advance를 켜면 팀이 다음 할 일을 스스로 가져갑니다
  • 예약 자동화 — 매시간·매일·매주·매월 반복 작업. 컴퓨터가 꺼져 있다 켜지면 최근 12시간 내 놓친 실행을 따라잡습니다

완료된 작업은 사람의 검토를 거쳐 돌아옵니다. 완전 무인은 아니고 "사람이 승인하는 루프"를 지향합니다.

연결과 커넥터

실무에 붙이려면 외부 서비스 연결이 필요합니다. Gmail·Google Calendar·Sheets·Drive·Notion·Slack·Shopify·Stripe 등 커넥터가 있습니다.

중요한 기본값: 보내기·게시·삭제 전에 기본적으로 물어봅니다. 에이전트가 메일을 발송하거나 슬랙에 올리기 전에 승인 단계가 들어갑니다. 이게 "자율적이지만 통제되는" 균형점입니다.

앱(Apps) 기능도 있습니다. "이런 도구가 필요해"라고 말하면 로컬 앱을 만들어 주고, 유료 플랜에서는 공개 링크가 달린 웹 앱으로도 발행됩니다.

로컬 우선이 실제로 뜻하는 것

이름 그대로 데이터가 기본적으로 내 디스크에 있습니다. 대화·파일·지식베이스·커스텀 에이전트가 로컬에 저장됩니다.

모델 호출은 두 가지 경로입니다. 자체 API 키를 쓰면 기기에서 프로바이더로 직접 나가고, Orkas 내장 모델을 쓰면 무료 크레딧 500이 제공됩니다(API 키 없이 시작 가능). 클라우드 동기화·공유 프로젝트·웹 앱 발행은 패키지 앱에서만 지원됩니다.

설치와 실행

macOS와 Windows용 데스크톱 앱을 다운로드합니다. 오픈소스 빌드도 있지만, 공유 프로젝트·클라우드 동기화·웹 앱 발행은 패키지 앱 전용입니다.

자체 키를 쓰려면 Settings → Models에서 프로바이더 키를 등록합니다. Claude·OpenAI·Gemini·DeepSeek·Kimi·GLM·Qwen·MiniMax·Doubao 또는 로컬 OpenAI 호환 엔드포인트를 지원합니다.

음성 입력도 지원합니다. Orkas API 키를 설정하고 마이크 버튼을 누르면, 음성이 인식돼 텍스트로 변환됩니다.

실제로 시켜보는 법

README가 보여주는 실제 사용 예시가 있습니다. VideoStudio로 참고 영상을 재현하는 프롬프트인데, 이런 식으로 구체적인 산출물을 요청하면 됩니다.

reference.mp4를 참고해서 30초 세로형 프로모션을 만들어줘.
훅, 타이포그래피, 페이싱은 유지하고 내용을 내 제품과 화면 녹화로 바꿔줘.
먼저 분석 결과와 계획을 보여줘.

포인트는 "먼저 보여줘"입니다. 에이전트가 바로 실행하지 않고 분석·계획을 먼저 제시하게 해서, 방향이 틀어졌을 때 되돌리기 쉽습니다. 이런 승인 루프가 Orkas의 기본 철학입니다.

비슷한 도구와의 차이

Claude Code 같은 단일 에이전트 도구와 달리 Orkas는 여러 에이전트의 오케스트레이션에 집중합니다. Conductor처럼 병렬 세션을 관리하는 도구와도 겹치지만, Orkas는 전문 분야 에이전트(리서치·문서·이커머스)까지 포함한다는 점이 다릅니다.

다만 생태계가 어리고(9천 stars) 많은 기능이 패키지 앱에 묶여 있어, 오픈소스만으로는 핵심 가치의 일부만 경험할 수 있습니다.

한계와 주의

  • 성숙도 — 신생 프로젝트라 안정성과 문서가 아직 다듬어지는 중입니다
  • 기능 이원화 — 공유 프로젝트·동기화·웹 발행은 유료/패키지 앱에서만 됩니다
  • 모델 비용 — 여러 에이전트가 동시에 돌면 API 비용이 커질 수 있습니다
  • 승인 피로 — 모든 외부 행위에 승인 버튼이 뜨면 오히려 불편할 수 있어, 규칙을 잘 설정해야 합니다

정리

Orkas는 "데스크톱에서 AI 팀을 굴리는" 실험적이지만 방향이 분명한 도구입니다. Commander가 목표를 할 일로 쪼개고, 전문 에이전트와 기존 코딩 에이전트가 협업하며, 투두와 자동화로 계속 진행되는 구조는 개인이 아니라 소규모 팀의 반복 업무에 잘 맞습니다. 아직 초기지만, 멀티에이전트 오케스트레이션이 어디로 가는지 보여주는 좋은 사례입니다.
