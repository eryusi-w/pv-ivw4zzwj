문제 제기

로봇이나 강화학습을 다루다 보면 물리 엔진 선택이 첫 관문입니다. 사실상 표준이 된 MuJoCo가 무엇이고 어떻게 쓰는지 정리했습니다.

무엇인가

관절형 강체 동역학과 접촉을 다루는 범용 물리 시뮬레이터입니다. 로봇 제어와 강화학습 환경의 사실상 표준으로 쓰입니다. 현재 GitHub 스타 17,562개, 주 언어는 C++입니다.

핵심 기능

  • 관절형 강체 동역학과 접촉 시뮬레이션
  • 브라우저에서 바로 체험 가능한 MuJoCo Studio 웹 버전
  • pip 패키지와 C++ 라이브러리 형태 제공
  • 로봇·강화학습 연구의 표준 벤치마크 환경

설치와 첫 실행
