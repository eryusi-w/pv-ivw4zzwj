Claude Code 시작하기, 설치부터 첫 명령까지

#ClaudeCode#설치방법#AI코딩#개발도구#Anthropic#오픈소스#프로그래밍#자동화#초보#생산성

Claude Code를 써보고 싶은데 "설치부터 어떻게 하지?" 막막하다면 이 글을 보세요. 설치부터 로그인, 첫 명령까지 초보가 따라 할 수 있게 정리했습니다.

Claude Code가 뭔가요

Claude Code는 Anthropic의 AI 코딩 에이전트입니다. 터미널에서 실행되며, 코드베이스를 읽고 수정·실행·디버깅을 대화로 시킵니다. VS Code 확장이나 JetBrains 플러그인으로도 쓸 수 있습니다.

설치 방법 — npm

가장 일반적인 설치 방법은 npm입니다. Node.js가 설치돼 있어야 합니다.

npm install -g @anthropic-ai/claude-code

설치 후 터미널에서 claude를 입력하면 실행됩니다.

설치 방법 — 네이티브 설치

Node.js가 없다면 OS별 네이티브 설치 프로그램도 있습니다.

  • macOS: brew install --cask claude-code 또는 공식 설치 스크립트
  • Windows: PowerShell 설치 스크립트 또는 npm
  • Linux: npm 또는 공식 스크립트

자세한 명령은 Anthropic 공식 문서(claude.com/code)를 확인하세요.

로그인과 첫 실행

처음 claude를 실행하면 로그인을 요구합니다. Claude 계정으로 로그인하거나 API 키를 입력합니다.

claude        # 실행 → 로그인 프롬프트

로그인 후 프로젝트 폴더에서 실행하면 Claude가 파일을 읽고 작업을 시작합니다. "이 코드 설명해줘" 같은 자연어로 시작하면 됩니다.

자주 쓰는 첫 명령

명령용도
/help명령어 목록 보기
/clear대화 초기화
/cost사용량·비용 확인
/init프로젝트 설정 파일 생성

주의할 점

  • 프로젝트 폴더에서 실행하세요 — Claude가 그 폴더의 파일을 읽습니다
  • 민감한 파일(.env 등)은 접근을 제한하는 게 좋습니다
  • 처음엔 읽기·설명 요청부터 시작해 결과를 확인하세요

정리

npm으로 설치하고 claude로 실행, 로그인 후 프로젝트 폴더에서 자연어로 지시하면 됩니다. /help로 명령어를 확인하고, 처음엔 읽기 작업부터 시작해보세요.

참고: Anthropic 공식 문서(claude.com/code)와 Claude Code GitHub 기준입니다.
