클로드 스킬 cartoon-3d-short, 쇼츠 자동 제작법

#Claude#클로드스킬#cartoon3dshort#쇼츠#애니메이션#Remotion#영상제작#AI활용#콘텐츠제작#개발도구

Claude Code에 "cartoon short 스킬로 ~에 대한 쇼츠를 만들어줘"라고 한 줄만 치면 55~70초 세로형 애니메이션 쇼츠가 나옵니다. AI 영상 생성기가 아니라 three.js + Remotion으로 직접 렌더링하는 방식입니다.

핵심 특징 3가지

  • 2D 캐릭터가 살아있는 3D 월드에서 움직이는 스토리형 쇼츠 — 인물선·렌즈블러·카메라 무빙 포함
  • three.js + Remotion 기반 로컬 렌더링 — 외부 AI 영상 API 없이 내 PC에서 완성
  • 주제→스크립트→보이스→샷 플랜→스틸→렌더→QA까지 파이프라인이 SKILL.md 하나에 정리

설치와 빠른 실행

저장소를 ~/.claude/skills/cartoon-3d-short/에 복사하면 끝입니다. 필요한 것은 Remotion(+@remotion/three), Node, Python 3, ffmpeg입니다.

git clone https://github.com/mromidev/claude-animated-shorts.git

실전 활용 시나리오

Claude Code에서 이렇게 요청하면 됩니다.

Use the cartoon short skill and make a short about [주제].

이후 흐름은 정해져 있습니다 — 주제와 사실 정리 → 스크립트 → 보이스 → 샷 플랜(story.ts) → 스틸 확인 → 렌더 → 프레임 단위 QA → 최종 2K 영상과 사운드 믹스. 에이전트가 중간 산출물을 검수합니다.

직접 쓰기 전 알면 좋은 점

  • REMOTION_TMP 필수 — Remotion이 번들마다 public/(약 1.3GB)을 임시 폴더에 복사하므로 큰 드라이브를 지정하세요
  • 레퍼런스는 스타일 참고용 — 포함된 프레임·리포트는 "-look"을 맞추는 용도이고, 스토리·캐릭터·보이스는 직접 만들어야 합니다
  • 렌더 비용 — AI API가 아니라 로컬 렌더링이라 GPU·시간이 듭니다. 짧은 테스트부터 확인하세요

누구에게 필요한가

유튜브 쇼츠·인스타 릴스를 직접 만들고 싶은 크리에이터, Claude Code를 이미 쓰는 분에게 적합합니다. 별도 AI 영상 구독 없이 애니메이션 영상을 뽑아보고 싶은 분도 후보입니다.

정리

Claude Code + 이 스킬이면 "한 줄 요청 → 55~70초 애니메이션 쇼츠" 파이프라인을 무료(MIT)로 재현할 수 있습니다. Remotion 환경과 REMOTION_TMP만 미리 잡아두세요.
