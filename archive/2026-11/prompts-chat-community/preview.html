프롬프트를 모아 나누는 prompts.chat

#prompts#프롬프트#커뮤니티#오픈소스#봇#에이전트#큐레이션#공유#라이선스#아카이브

문제 제기

좋은 프롬프트는 대화 속에 갇힙니다. 누군가 ChatGPT에 넣어 잘 먹힌 문장을 봐도, 나중에 그걸 다시 찾을 방법이 없습니다. 프롬프트를 모으는 awesome list는 넘쳐나지만, 검색하고 복사하고 다시 기여하는 "장소"는 드뭅니다.

prompts.chat(f/prompts.chat)은 이 문제를 푼 최초의 프롬프트 라이브러리입니다. 2022년 12월에 시작해 GitHub 별 17만 6천 개, 포크 2만 2천 개를 기록했습니다. 옛 이름은 Awesome ChatGPT Prompts입니다.

세계 최대의 오픈소스 프롬프트 라이브러리이자, 프롬프트를 넘어 봇과 봇 팀까지 아우르는 커뮤니티 플랫폼입니다.

무엇이 다른가

단순한 마크다운 목록이 아닙니다. 웹사이트(prompts.chat)에서 프롬프트를 검색·복사·기여하고, 같은 데이터가 prompts.csv, PROMPTS.md, Hugging Face 데이터셋으로도 배포됩니다. 프롬프트를 추가하면 웹에서 자동으로 저장소에 동기화됩니다.

Hugging Face에서 가장 좋아요를 받은 데이터셋 중 하나이고, Forbes에 소개됐으며 Harvard와 Columbia가 참고 자료로 인용했습니다. 학술 인용도 40건 이상입니다. OpenAI 공동창업자 Greg Brockman과 Wojciech Zaremba, Hugging Face CEO Clement Delangue, 전 GitHub CEO Thomas Dohmke가 공개적으로 호평한 프로젝트이기도 합니다.

라이선스 구성 — 저장소에 CC0-1.0, MIT 등 여러 라이선스 파일이 있습니다. 프롬프트 데이터의 재사용 조건은 각 파일의 라이선스를 확인해야 합니다.

프롬프트 라이브러리

ChatGPT용으로 시작했지만 지금은 Claude, Gemini, Llama, Mistral 등 모든 모델에서 쓸 수 있는 프롬프트를 모읍니다. 사이트에서 검색하고 복사하면 끝이고, 새 프롬프트는 prompts.chat/prompts/new에서 추가하면 저장소로 자동 동기화됩니다.

데이터 형식이 세 갈래라 용도에 따라 고르면 됩니다. 사람이 읽기엔 PROMPTS.md, 스크립트로 쓰기엔 prompts.csv, 머신러닝 데이터셋으로는 Hugging Face 버전을 씁니다.

프롬프팅 교과서

저장소에는 무료 인터랙티브 교과서가 들어 있습니다. The Interactive Book of Prompting은 30개 이상의 챕터로 기본부터 chain-of-thought, few-shot learning, AI 에이전트까지 다루고, 최신 챕터는 "프롬프트에서 팀으로"(prompt → skill → agent → bot → team), 상시 가동 봇, 컴퓨터 사용까지 확장됐습니다. 17개 언어로 제공됩니다.

어린이용으로는 Prompting for Kids(Promi)가 따로 있습니다. 8~14세 대상의 게임형 학습으로, 퍼즐과 스토리로 AI와 대화하는 법을 가르칩니다.

봇과 봇 팀

prompts.chat이 프롬프트 라이브러리를 넘어선 이유가 여기 있습니다. 사이트는 상시 가동 AI 에이전트와 그들이 일하는 팀을 호스팅합니다.

  • Bots — OpenClaw, Hermes Agent, Grok Bot 등의 봇을 공유·발견합니다. 각 봇 페이지에 플랫폼별 설치법, 필요한 컴퓨터(cloud/사용자 컴퓨터/둘 다), "함께 쓰면 좋은" 페어링, 업보트, 코멘트가 붙습니다.
  • Bot Teams — 봇들이 서로 작업을 넘기는 그룹으로, 인터랙티브 그래프로 보여 줍니다. 팀 단위로 업보트하거나 봇을 한 번에 설치할 수 있고, JSON API(GET /api/teams)로도 조회됩니다.
  • 모더레이션 — 봇과 팀은 unlist 처리해 공개 목록에서 숨길 수 있습니다.

"프롬프트를 모은다"에서 "에이전트 생태계를 공유한다"로 확장된 셈입니다.

연동 방법

세 가지 경로가 있습니다. CLI, Claude Code 플러그인, MCP 서버입니다.

# CLI
npx prompts.chat

# Claude Code 플러그인
/plugin marketplace add f/prompts.chat
/plugin install prompts.chat@prompts.chat

# MCP 서버 (원격)
{ "mcpServers": { "prompts.chat": { "url": "https://prompts.chat/api/mcp" } } }

MCP 서버는 프롬프트와 스킬 검색뿐 아니라 봇(search_bots, get_bot, save_bot)과 팀(list_teams, get_team, save_team) 도구까지 제공합니다. 로컬 실행은 npx prompts.chat mcp입니다.

셀프 호스팅

조직 내부에서 프라이빗하게 쓰고 싶다면 셀프 호스팅이 됩니다. Next.js + PostgreSQL 기반이고, Docker 가이드와 셀프 호스팅 문서가 따로 있습니다.

# 대화형 마법사로 새 프로젝트 생성
npx prompts.chat new my-prompt-library
cd my-prompt-library

# 또는 직접 클론
git clone https://github.com/f/prompts.chat.git
cd prompts.chat
npm install && npm run setup

마법사가 브랜딩, 테마, 인증(GitHub/Google/Azure AD), 기능을 설정합니다. DB는 PostgreSQL이 권장이고 Neon 같은 호스티드 DB를 쓰면 됩니다. 사내 프롬프트를 외부에 안 보이게 관리해야 하는 조직에 특히 맞는 기능입니다.

한계와 주의

커뮤니티 라이브러리의 고질적 문제가 있습니다. 프롬프트의 품질이 제각각이고, 잘 작동하던 프롬프트가 모델 업데이트로 깨질 수 있습니다. 사이트에 있는 프롬프트가 전부 검증된 건 아니니, 복사해 쓰기 전에 내 작업에서 한 번 테스트하는 게 맞습니다.

봇과 팀 기능은 2026년에 들어와 확장된 영역이라 아직 초기입니다. 팀 JSON API는 있으나, 팀이 실제로 잘 작동하는지는 개별 검증이 필요합니다. 셀프 호스팅은 PostgreSQL과 인증 설정이 필요해, 간단한 용도라면 공개 사이트를 쓰는 게 훨씬 빠릅니다.

누구에게 맞나

프롬프트를 처음 모으기 시작하는 사람, 사내 프롬프트를 체계화하고 싶은 팀, 에이전트 생태계를 둘러보고 싶은 사람에게 맞습니다. 이미 프롬프트 엔지니어링을 잘하는 사람에게는 교과서의 고급 챕터와 봇 팀 구조가 새로운 관점을 줄 수 있습니다.

반대로 특정 모델 전용 프롬프트나 최신 연구 프롬프트를 찾는다면 이곳보다 각 모델의 공식 문서나 최신 논문이 낫습니다. prompts.chat은 커뮤니티가 검증한 실전 프롬프트의 집합이지, 최신 기법의 발표장이 아닙니다.

도입 전 체크리스트

확인할 것 4가지

✓ 용도 — 프롬프트 검색인지, 봇/팀 공유인지, 셀프 호스팅인지

✓ 연동 — CLI / Claude Code 플러그인 / MCP 중 환경에 맞는 것

✓ 검증 — 커뮤니티 프롬프트는 내 작업에서 한 번 테스트

✓ 라이선스 — CC0/MIT 혼재, 재배포 조건 확인

정리

prompts.chat은 "프롬프트를 모아 나누는" 원래 목적을 넘어, 교과서와 봇 생태계와 셀프 호스팅까지 아우르는 플랫폼이 됐습니다. 2022년의 첫 프롬프트 라이브러리가 2026년에는 AI 에이전트 팀의 공유소가 된 겁니다.

오늘 해 볼 일은 prompts.chat 사이트에서 자기 작업과 비슷한 프롬프트 하나를 찾아 복사해 보는 겁니다. 그리고 MCP 서버를 연결하면 에이전트가 이 라이브러리를 직접 검색하게 할 수도 있습니다.
