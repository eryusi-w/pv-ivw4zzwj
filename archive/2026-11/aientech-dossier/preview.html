프로필로 이력서·자소서를 자동 생성 (dossier)

#AI도구#오픈소스#dossier#문서지식#생산성#자동화#개발도구#업무효율#프로필기반이력서자동생성#구인공고분석및맞춤커버레터초안작성

문서·지식 쪽에서 반복되는 작업을 도구로 줄이려다 보면 설치 단계에서 먼저 막힙니다. 문서는 영어로 길고, 예제는 버전이 맞지 않고, 무엇부터 확인해야 하는지도 정해져 있지 않습니다.

dossier는 프로필을 바탕으로 맞춤 이력서와 자기소개서를 만들어 주는 자체 호스팅형 구직 지원 앱입니다. 개인정보를 외부에 두지 않고, AI 모델로 직무별 문서를 자동 생성하고 지원 과정을 추적합니다. 현재 GitHub 스타 4,143개, 주 언어는 TypeScript입니다. 설치부터 실제 작업에 붙이는 순서까지 정리했습니다.

핵심 특징 3가지

  • 프로필 기반 이력서 자동 생성
  • 구인 공고 분석 및 맞춤 커버레터 초안 작성
  • 지원서 작성 단계별 대화형 편집

설치와 빠른 실행

docker compose up -d

릴리즈 페이지에서 Docker 이미지를 내려받아 Docker Compose로 실행하면 됩니다.

실전 활용 시나리오

처음부터 크게 붙이지 말고, 아래 순서로 작은 작업 하나에만 적용합니다.

git clone https://github.com/AienTech/dossier.git
  • 1단계 — 설치 명령으로 도구를 준비합니다.
  • 2단계 — 프로필을 등록하고 지원할 공고를 붙여 넣으면 초안이 나옵니다.
  • 3단계 — 결과 파일과 로그를 열어 기대한 값이 나왔는지 확인합니다.
  • 4단계 — 괜찮으면 같은 방식을 두 번째 작업으로 넓힙니다.

직접 쓰기 전 알면 좋은 점

AGPL-3.0 라이선스라 상업적 서비스에 그대로 올리기는 제약이 있습니다. 개인 용도나 내부 도구로 쓰는 분에는 문제없습니다.

누구에게 필요한가

이력서와 자소서 초안을 빠르게 뽑아 보고 싶은 구직자, 프리랜서에게 맞습니다. 개인정보가 들어가는 만큼 직접 서버에 올려 쓰는 구조를 택한 점도 괜찮은 선택입니다.

정리

프로필 한 번 등록으로 이력서·자소서 초안을 계속 다시 쓸 수 있는 도구입니다. 다만 스타 4천 개대의 비교적 새 프로젝트라, 지원 과정 전체를 이 도구 하나에 맡기기보다 초안 생성 용도로 먼저 써보는 게 안전합니다.
