내 PC에서 무료 ChatGPT: Ollama + Open-WebUI

#Ollama#OpenWebUI#로컬LLM#ChatGPT#AI#Docker#오픈소스#RAG#자율주행#프로그래밍

내 PC에서 무료 ChatGPT를 직접 돌린다고?

"ChatGPT 구독료가 부담스럽다" "데이터가 밖으로 나가는 게 싫다" "오프라인에서도 AI를 쓰고 싶다" 이런 고민을 한 번쯤은 해보셨을 겁니다. 오픈소스 LLM과 웹 UI를 조합하면, 구독료 없이, 데이터가 PC 밖으로 나가지 않는, 완전한 로컬 ChatGPT를 만들 수 있습니다.

이 글에서는 Ollama(로컬 LLM 실행 엔진)와 Open-WebUI(ChatGPT 스타일 웹 인터페이스)를 도커로 묶어, 5분 만에 내 PC에서 돌아가는 무료 ChatGPT를 만드는 방법을 정리했습니다. GPU가 없어도 CPU 모드로 작동하며, Windows/macOS/Linux 모두 지원합니다.

구성 요소: Ollama + Open-WebUI

두 도구의 역할은 명확합니다. Ollama는 모델을 메모리에 올리고 추론 API를 제공하며, Open-WebUI는 사용자 친화적인 채팅 인터페이스를 제공합니다.

도구 역할 특징
Ollama LLM 서빙 엔진 모델 다운로드, 양자화, GPU/CPU 자동 감지
Open-WebUI 웹 채팅 UI ChatGPT 스타일, RAG, 모델 관리, 다중 사용자

왜 로컬 LLM인가

로컬 LLM을 쓰는 이유는 세 가지입니다.

1. 비용 제로: 월 구독료 $20(약 28,000원)가 들지 않습니다. 전기세만 내면 무제한 사용 가능합니다.

2. 데이터 프라이버시: 대화 내용, 코드, 문서가 내 PC 밖으로 나가지 않습니다. 기업 기밀, 개인 정보를 다루는 업무에 안전합니다.

3. 오프라인 작동: 인터넷이 안 되는 환경(비행기, 보안 구역, 출장지)에서도 AI를 쓸 수 있습니다.

단점도 있습니다. 최신 GPT-4o나 Claude 3.5 Sonnet 수준의 추론 능력은 기대하기 어렵습니다. 하지만 코딩 보조, 요약, 번역, 아이디어 발상 등 일상 업무에는 충분합니다.

5분 설치: Docker Compose로 한 번에

가장 간단한 방법은 Docker Compose입니다. 아래 파일을 저장하고 실행하면 끝입니다.

# docker-compose.yml
version: '3.8'
services:
  ollama:
    image: ollama/ollama:latest
    container_name: ollama
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]

  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    container_name: open-webui
    ports:
      - "3000:8080"
    environment:
      - OLLAMA_BASE_URL=http://ollama:11434
      - WEBUI_SECRET_KEY=your-secret-key-here
    volumes:
      - openwebui_data:/app/backend/data
    depends_on:
      - ollama

volumes:
  ollama_data:
  openwebui_data:

실행 명령어:

docker compose up -d

Windows라면 Docker Desktop이 설치되어 있어야 합니다. docker compose up -d 실행 후 http://localhost:3000으로 접속하면 계정 생성 화면이 나옵니다. 첫 계정은 자동으로 관리자가 됩니다.

추천 모델: 용도별 선택 가이드

Ollama에서 모델을 내려받으려면 웹 UI의 설정 → 모델 관리에서 모델 이름을 입력하거나, 터미널에서 직접 받습니다.

용도 모델명 크기 필요 VRAM/RAM
범용/코딩 qwen2.5-coder:7b 4.7 GB 8 GB
한국어 특화 eeve-korean:10.8b 6.5 GB 10 GB
경량/빠름 gemma2:2b 1.6 GB 4 GB
고성능 llama3.1:8b 4.9 GB 8 GB
이유ing/수학 deepseek-r1:7b 4.7 GB 8 GB

모델 다운로드 명령어:

# 웹 UI에서: 설정 → 모델 → "qwen2.5-coder:7b" 입력 → 다운로드
# 또는 터미널에서:
docker exec -it ollama ollama pull qwen2.5-coder:7b

Open-WebUI 핵심 기능

단순 채팅을 넘어선 강력한 기능들이 내장되어 있습니다.

1. RAG (문서 기반 질의응답): PDF, TXT, MD 파일을 업로드하면 문서 내용을 바탕으로 답변합니다. "이 계약서에서 위약금 조항 찾아줘" 같은 질문이 가능합니다.

2. 모델 동시 실행: 여러 모델을 동시에 띄워 놓고, 질문마다 다른 모델을 선택할 수 있습니다. 코딩은 qwen2.5-coder, 한국어 번역은 eeve-korean 식으로 용도별 분리가 가능합니다.

3. 프롬프트 템플릿: 자주 쓰는 프롬프트를 템플릿으로 저장해 한 번의 클릭으로 불러옵니다. "코드 리뷰어", "영어 번역기", "SQL 작성기" 등 역할별 템플릿을 만들어 두면 편합니다.

4. 웹 검색 연동: DuckDuckGo, Google 검색 API를 연결하면 실시간 정보를 반영한 답변을 받을 수 있습니다.

5. 다중 사용자/권한 관리: 팀원들과 공유하려면 사용자 계정을 추가하고 권한을 설정하면 됩니다.

GPU가 없어도 된다: CPU 모드 최적화

NVIDIA GPU가 없는 노트북/데스크톱에서도 작동합니다. Ollama는 자동으로 CPU 모드로 전환하며, 양자화된 모델(4-bit, 8-bit)을 쓰면 메모리 사용량을 크게 줄일 수 있습니다.

CPU 최적화 팁:

  • 작은 모델 쓰기: gemma2:2b(1.6GB), phi3:mini(2.3GB) 등은 8GB RAM 노트북에서도 쾌적합니다.
  • 스왑 늘리기: Windows라면 가상 메모리를 16GB 이상으로 설정하세요.
  • 스레드 수 제한: OLLAMA_NUM_THREADS=4 환경변수로 CPU 점유율을 조절할 수 있습니다.
# docker-compose.yml에 환경변수 추가
environment:
  - OLLAMA_NUM_THREADS=4
  - OLLAMA_MAX_LOADED_MODELS=1

실제 사용 후기: 개발자 관점

RTX 3080(10GB VRAM) 데스크톱과 M2 MacBook Air(16GB 통합 메모리)에서 2주간 사용해 보았습니다.

만족스러운 점:

  • 코딩 보조: qwen2.5-coder:7b로 Python, TypeScript 코드 작성/리뷰가 충분히 가능합니다. "이 함수 리팩터링해줘", "테스트 코드 짜줘" 프롬프트에 즉각 반응합니다.
  • 문서 요약/번역: 50페이지 PDF를 업로드하고 "핵심 3줄로 요약" 요청하면 10초 내에 나옵니다.
  • 데이터 안전: 회사 코드를 붙여넣어도 외부 전송 걱정 없습니다. .gitignore에 ollama_data만 추가하면 됩니다.

아쉬운 점:

  • 긴 컨텍스트: 8K~32K 컨텍스트 윈도우라 대형 코드베이스 전체를 한 번에 넣기 어렵습니다. (RAG로 보완 가능)
  • 한국어 품질: 영문 모델은 한국어 답변이 어색할 수 있습니다. eeve-korean 같은 한국어 특화 모델 병행을 추천합니다.
  • 첫 로딩 시간: 모델이 메모리에 없으면 첫 요청 시 10~30초 로딩이 걸립니다. ollama run으로 미리 올려두면 해결됩니다.

문제 해결 FAQ

증상 원인/해결
"Connection refused" Ollama 컨테이너가 아직 안 뜸. docker logs ollama 확인
모델 다운로드 멈춤 네트워크/디스크 공간 확인. ollama pull 재시도
메모리 부족(OOM) 더 작은 모델 사용, 스왑 늘리기, MAX_LOADED_MODELS=1
답변이 너무 느림 CPU 모드면 GPU 확인, 양자화 모델 사용, 스레드 수 조정

더 나아가기: 외부 접근, 백업, 업데이트

외부에서 접속하려면: Tailscale, Cloudflare Tunnel, ngrok 등으로 3000 포트를 안전하게 노출하면 집 밖에서도 내 로컬 ChatGPT를 쓸 수 있습니다.

데이터 백업: docker compose down -v 하면 볼륨이 삭제되니 주의하세요. 정기 백업은 볼륨 마운트 경로(/var/lib/docker/volumes/)를 복사하거나, Open-WebUI의 내보내기 기능을 쓰세요.

업데이트: docker compose pull && docker compose up -d로 최신 이미지를 받아 재시작하면 됩니다. 모델 데이터는 볼륨에 별도 보관되어 유지됩니다.

마무리

Ollama + Open-WebUI 조합은 "내 PC에서 무료로, 프라이빗하게, 오프라인에서도 ChatGPT를 쓰기" 위한 가장 실용적인 해법입니다. Docker 한 줄로 5분이면 구축되고, 모델만 골라 담으면 바로 쓸 수 있습니다.

완벽한 GPT-4 대체제는 아니지만, 일상적인 코딩 보조, 문서 요약, 번역, 아이디어 발상 용도로는 월 28,000원 아끼면서 충분히 쓸 만합니다. 오늘 저녁 퇴근길에 docker compose up -d 한 번 돌려보세요. 내일이면 나만의 AI 비서가 기다리고 있을 겁니다.
