코드베이스를 질문으로 바꾸는 사고방식

"코드베이스가 커질수록 매일 같은 질문을 반복하게 된다. 어디서 어떤 파일이 쓰이는지, A에서 B로 출력이 어떤 경로로 가는 것인지, 이전 로직을 그대로 가져오려면 어떻게 해야 하는지. IDE 검색만으로는 매번 시간을 낭비하게 된다.

Graphify는 코드베이스를 지능형 그래프로 변환해 주는 도구다. 139,000개의 GitHub Star를 받은 Graphify-Labs 오픈소스 프로젝트로, Claude Code, Cursor, Codex, Gemini CLI 등 20개 이상 AI 코딩 도구와 연동되어 사용한다. "코드를 질문하니 코드 질문이냐?"는 의아해 할 수 있지만, 실제로 코드의 의도를 질문 형태로 바꿔주면 문제를 빠르게 해결할 수 있다.

Graphify 핵심 기능

Graphify는 코드베이스를 지식 그래프로 변환해 5가지 핵심 기능을 제공한다. 기능을 조합하면 대규모 코드베이스도 손쉽게 탐색할 수 있다.

기능 설명
AST 분석코드 구조를 추상 문법 트리로 분석
의도 추출의도된 기능과 로직을 파악
그래프 변환코드를 관계 그래프로 변환
질의하기그래프를 통해 원하는 정보 조회
통합 가능AI 코딩 도구와 연동 가능

이런 문제를 해결해 준다

"코드를 질문으로 바꾸면 코드 질문이냐?"고 의아해 할 수 있지만, 실제로 코드의 의도를 질문 형태로 바꾸면 훨씬 빠르게 문제를 해결할 수 있다. 139,000개의 GitHub Star를 받은 Graphify-Labs 오픈소스 프로젝트로, Claude Code, Cursor, Codex, Gemini CLI 등 AI 코딩 도구와 연동되어 사용한다. 코드, 문서, SQL키파일, PDF까지 모든 것을 지식 그래프로 변환해 질의해 주면 원하는 정보를 쉽게 찾을 수 있다.

주요 사용 사례

  • 코드베이스가 커질 때마다 매번 grep, find, IDE 검색으로 시간을 낭비하지 않으려는 경우
  • 리팩터링 전 기존 로직의 의도와 연결 관계를 파악해야 하는 경우
  • 새로운 팀원이 합류했을 때 코드베이스 빠르게 온보딩하고자 하는 경우
  • 다운스트림 영향도를 파악해야 하는 디버깅 상황

시작 방법

Graphify는 다양한 AI 코딩 도구와 연동된다. Claude Code, Cursor, Codex, Gemini CLI 등을 사용 중이라면 바로 시도해 볼 수 있다. 139,000개의 GitHub Star를 받은 프로젝트답도 즉시 사용 가능한 커맨드나 플러그인이 제공된다.
