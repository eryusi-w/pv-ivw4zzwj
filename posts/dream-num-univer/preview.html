기타 AI 도구 분야의 오픈소스 프로젝트입니다 (univer)

#AI도구#오픈소스#univer#기타AI도구#생산성#자동화#개발도구#업무효율#board#collaboration

AI와 의사소통하는 동시에 반복적인 문서·시트 작업까지 자동화하고 싶으신가요? 기존 office SDK는 무게가 무거워서 에이전트가 다루기 어렵고, 클라우드 의존도가 높아 자체 호스팅 시 보안 관리가 번거롭습니다.

univer(dream-num/univer)은 Open Source Office SDK로, 빠진 설치 절차 없이 AI 에이전트가 문서를 생성·수정할 수 있는 핵심 엔진을 제공합니다. GitHub 스타 25,000+를 확보한 실전용 도구입니다.

핵심 특징 3가지

  • AI 에이전트 친화적 — Facade API로 문서 구조를 이해하고, 명령(Mutation)으로 안전하게 편집합니다.
  • 클라이언트 사이드 편집 — 웹 SDK로 브라우저에서 직접 작업, 서버 없이도Sheets·Docs·Slides를 작성합니다.
  • 확장 가능한 플러그인 — 피처 플러그인으로 필터·차트·식을 자유롭게 추가하고, AgentRun과 연동해 워크플로우 자동화가 가능합니다.

설치와 빠른 실행

npm install @univerjs/sheets-core @univerjs/design @univerjs/ui
npx univer run --port 5173

Apache-2.0 라이선스의 오픈소스입니다. 설치 후 공식 문서에서 빠른 시작 가이드를 확인하세요.

실전 활용 시나리오

처음부터 크게 붙이지 말고, 아래 순서로 작은 작업 하나에만 적용합니다.

npm create univer@latest my-univer-app
cd my-univer-app
npx univer dev
  • 1단계 — npm 플러그인으로 univer SDK를 프로젝트에 추가합니다.
  • 2단계 — Sheets Core 프리셋로 기본 문서 편집 기능을 확인합니다.
  • 3단계 — 코드를 수정하고 npx univer dev로 HMR로 확인합니다.
  • 4단계 — 필요한 기능을 플러그인으로 확장하고 배포합니다.

직접 쓰기 전 알면 좋은 점

버전 간 호환성을 위해 @univerjs/* 패키지는 같은 버전으로 묶어 설치하고, 피처 플러그인은 프리셋에 맞게 선택하세요.

누구에게 필요한가

AI 에이전트가 문서 작업을 자동화하려는 개발자·엔지니어에게 필수적입니다. 특히 AgentRun, Claude Code, Codex와 연동해 워크플로우 자동화를 구축하는 경우에 유용합니다.

정리

univer은 AI 에이전트가 문서를 이해하고 편집할 수 있도록 하는 Open Source Office SDK입니다. 빠른 시작 후 작은 기능부터 확장해 보세요.
