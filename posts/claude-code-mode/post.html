클로드 코드로 "프로젝트 전체에서 이 함수 찾아서 고치고 테스트 돌려줘"라고 하면 도구를 하나씩 호출합니다. 파일 검색 → 결과 읽기 → 편집 → 테스트 실행, 매번 왕복이 생기고 그 사이 토큰이 계속 쌓입니다.

Code Mode는 이 방식을 바꾸는 실험 기능입니다. 클로드가 자바스크립트를 직접 작성해 여러 도구 호출을 한 번에 묶어 실행하게 합니다. 2026년 11월 12일 Claude Code v2.1.323에 추가됐고, 기본은 꺼져 있습니다.

핵심 특징 3가지

  • 코드로 도구 호출 — 클로드가 Bash·Read·Edit 같은 도구를 자바스크립트 함수처럼 호출하는 코드를 작성하고, 세션 안에서 실행합니다.
  • 왕복 감소 — 한 조각의 코드가 명령을 병렬로 돌리고, 한 결과를 다음 호출에 쓰고, 필요한 출력만 클로드에게 돌려줍니다.
  • 투명한 확인 — 대화에는 도구 호출(편집 diff 등)만 보이고, 코드 자체는 Ctrl+O 트랜스크립트 뷰어에서 Code 행으로 펼쳐 볼 수 있습니다.

설치와 빠른 실행

CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude

환경 변수로 켭니다. Windows는 PowerShell에서 $env:CLAUDE_CODE_EXPERIMENTAL_CODE_MODE = "1" 후 claude를 실행하거나, ~/.claude/settings.json의 env 블록에 넣으면 매 세션에 적용됩니다. 첫 실행 때 확인을 묻고, 동의하면 세션 상단에 "Code Mode (experimental) is on"이 표시됩니다.

실전 활용 시나리오

여러 파일에 걸친 반복 수정, 결과를 걸러야 하는 검색, 동시에 돌릴 수 있는 독립 명령이 어울립니다. 작은 수정 한두 개에는 오히려 번거로울 수 있습니다.

Read every Markdown file in this project and list the links that point to local files that don't exist.
  • 1단계 — 환경 변수를 켜고 claude를 실행한 뒤, 확인 프롬프트에서 "Yes, turn on Code Mode"를 선택합니다.
  • 2단계 — "프로젝트의 모든 마크다운 파일을 읽고 깨진 로컬 링크를 목록으로"처럼 도구 호출이 여러 번 필요한 작업을 맡깁니다.
  • 3단계 — 대화에는 편집 diff와 명령 결과만 보이고, 코드가 궁금하면 Ctrl+O로 열어 Code 행을 펼칩니다.
  • 4단계 — 나중에 이어서 하려면 claude --continue 실행 시에도 환경 변수를 1로 유지해야 합니다. 끄면 재개가 거부됩니다.

직접 쓰기 전 알면 좋은 점

실험 기능이라 언제든 바뀌거나 사라질 수 있습니다. 코드가 오래 걸리면 백그라운드로 넘기지 않으면 10분에서 멈추고, Remote Control·Claude in Chrome·컴퓨터 사용은 Code Mode 세션에서 쓸 수 없습니다. auto 모드에서는 분류기가 도구 호출이 아니라 코드 자체를 검토하므로, 반드시 통제해야 하는 호출은 규칙이나 훅으로 남겨 두는 게 안전합니다.

누구에게 필요한가

클로드 코드로 대규모 리팩터링이나 여러 파일을 오가는 작업을 자주 하는 개발자에게 맞습니다. 외부 실측 사례에서는 도구 호출 12회 왕복이 1회 코드 실행으로 줄고 토큰이 약 82% 감소했다고 보고됐지만, 작업에 따라 차이가 크니 본인 저장소에서 직접 비교해 보는 게 정확합니다.

정리

도구 호출을 하나씩 묻는 대신 자바스크립트 한 조각으로 묶어 실행하는 실험 기능입니다. 토큰과 대화 턴을 줄이는 방향이라 이 블로그에서 다뤄 온 토큰 절감 주제와 정확히 이어집니다. 실험 단계인 만큼 끄고 켜는 방법과 제한 조건을 알고 쓰면 됩니다.
