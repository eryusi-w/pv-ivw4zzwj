코딩 에이전트에게 화면을 맡기면 결과가 매번 비슷합니다. 보라색 그라데이션, 둥근 카드 안의 카드, 회색 배경 위 회색 글씨. "더 예쁘게"라고 해도 에이전트는 같은 기본값으로 돌아갑니다.

impeccable은 이런 AI 특유의 슬롭 디자인을 잡아주는 디자인 어휘 스킬입니다. 명령어 24개와 결정적 탐지 규칙 62개로 구성돼 있고, Claude Code·Cursor·Codex·Copilot 등 16개 이상의 코딩 도구에 설치됩니다. GitHub 스타 약 11만 개, Apache-2.0 라이선스입니다.

핵심 특징 3가지

  • 24개 디자인 명령 — bolder(더 과감하게), quieter(차분하게), typeset(타이포 수정), layout(간격 교정), polish(출시 전 마무리) 등 작업별 플레이북을 불러옵니다.
  • 62개 슬롭 탐지 규칙 — LLM 없이 동작하는 결정적 규칙이 AI 디자인의 전형적인 흔적(과도한 그라데이션, 잘못된 대비, 빈 헤딩 점프)을 파일 저장 즉시 잡습니다.
  • 3가지 탐지 경로 — 에이전트 훅(편집할 때마다 자동 검사), CLI(npx impeccable detect), 크롬 확장(실제 페이지 위에 오버레이)으로 같은 규칙을 돌립니다.

설치와 빠른 실행

npx impeccable install

설치 프로그램이 사용 중인 코딩 도구를 찾아 프로젝트용/전역용을 묻고, 지원되는 도구에는 디자인 훅 설치를 제안합니다. 설치 후 에이전트를 재시작하고 프로젝트에서 /impeccable init을 실행하면 제품 정보를 담은 PRODUCT.md가 만들어집니다.

실전 활용 시나리오

처음부터 크게 붙이지 말고, 아래 순서로 기존 화면 하나에만 적용합니다.

npx impeccable detect src/
  • 1단계 — /impeccable init으로 PRODUCT.md를 만들고, 기존 디자인 시스템이 있으면 /impeccable document로 DESIGN.md도 생성합니다.
  • 2단계 — CLI로 문제 지점을 먼저 봅니다. npx impeccable detect src/는 소스 파일의 패턴 규칙을, URL을 넣으면 렌더링된 페이지의 대비·글자 크기 규칙까지 검사합니다.
  • 3단계 — 에이전트에게 좁은 대상을 지시합니다. /impeccable critique the pricing cards처럼 "전체 페이지"보다 "요금 카드"가 결과가 좋습니다.
  • 4단계 — 자주 쓰는 명령은 /impeccable pin audit으로 단축키화해 /audit만 쳐도 되게 만듭니다.

직접 쓰기 전 알면 좋은 점

가장 강한 점은 "이미 있는 화면을 다듬는 것"입니다. 새 페이지 제작도 되지만, README도 기존 프로젝트 개선에 더 적합하다고 안내합니다. live 모드는 로컬 개발 서버 전용이라 배포된 사이트에 주입하거나 프로덕션 CSP를 약하게 만들어서는 안 됩니다.

누구에게 필요한가

AI 에이전트로 랜딩페이지·대시보드·앱 화면을 만들면서 "다 똑같아 보인다"고 느낀 개발자에게 맞습니다. 디자인 감각을 프롬프트로 설명하기 어려운 사람일수록 명령어 단위 플레이북이 도움이 됩니다.

정리

디자인을 "더 예쁘게"가 아니라 명령 단위로 지시하게 해주는 스킬입니다. init 한 번과 detect 한 번으로 시작할 수 있고, 스타 11만 개 규모의 커뮤니티가 유지보수를 뒷받침합니다.
