악성코드 분석이나 펌웨어 리버스 엔지니어링은 도구가 있어도 사람이 일일이 뜯어봐야 하는 작업입니다. rea는 이 과정을 AI 에이전트에게 맡기는 CLI 도구입니다.

바이너리부터 번들, 앱 동작까지 에이전트가 분석·복원하는 리버스 엔지니어링 도구로, MIT 라이선스에 현재 GitHub 스타 408,583개, 주 언어는 TypeScript입니다.

핵심 특징 3가지

  • AI 기반 분석 엔진 — 바이너리를 자동으로 디컴파일하고 동작을 추적합니다.
  • 앱 동작 역추적 — 애플리케이션 레벨에서 코드가 어떻게 움직이는지 복원합니다.
  • 대화형 CLI — Claude Code, Codex와 연동돼 질문하며 분석을 이어갈 수 있습니다.

설치와 빠른 실행

npm install -g rea

전역 설치 후 CLI에서 분석할 대상 파일이나 앱을 지정합니다. 결과는 대화형으로 이어서 파고들 수 있습니다.

실전 활용 시나리오

처음부터 큰 바이너리 말고, 직접 만든 작은 프로그램이나 의심 파일 하나로 시작합니다.

git clone https://github.com/morluto/rea.git
  • 1단계 — npm으로 rea를 설치하고 CLI가 뜨는지 확인합니다.
  • 2단계 — 분석할 바이너리나 앱 경로를 지정해 첫 분석을 실행합니다.
  • 3단계 — 출력된 구조와 호출 관계를 보며 궁금한 지점을 질문합니다.
  • 4단계 — 결과가 쓸 만하면 보안 감사나 문서화 작업에 재사용합니다.

직접 쓰기 전 알면 좋은 점

상세한 사용 설명서가 부족하고, 대규모 바이너리를 분석하면 시간이 오래 걸리거나 성능이 떨어질 수 있습니다. 결과는 참고 자료일 뿐이라 중요한 판단은 사람이 다시 검증해야 합니다.

누구에게 필요한가

보안 연구원, 역공학 전문가, AI 기반 개발 도구를 쓰는 개발자에게 특히 유용합니다. 악성코드·펌웨어 분석처럼 사람이 일일이 하기엔 시간이 많이 드는 작업을 줄이고 싶은 경우에 맞습니다.

정리

리버스 엔지니어링의 반복 작업을 에이전트에게 넘기는 도구입니다. 분석 결과를 그대로 믿기보다 단서를 얻는 용도로 쓰면 시간을 크게 아낄 수 있습니다.
