윈도우를 쓰다 보면 "이거 왜 없지?" 하는 기능이 한둘이 아닙니다. 파워토이즈(PowerToys)는 마이크로소프트가 공식으로 만든 유틸리티 모음으로, 이런 빈틈을 메우는 도구입니다.

파워토이즈란

PowerToys는 윈도우 10·11용 생산성 유틸리티 모음입니다. GitHub 저장소 microsoft/PowerToys는 스타 약 14만 개, MIT 라이선스의 오픈소스입니다. 개별 도구를 하나씩 깔 필요 없이 하나의 앱에서 모듈을 켜고 끌 수 있습니다.

설치와 시작

Microsoft Store 또는 GitHub 릴리스에서 설치합니다. 설치 후 트레이 아이콘을 클릭하면 각 모듈을 개별적으로 활성화할 수 있습니다. 처음엔 전부 켜기보다 필요한 것만 켜는 게 좋습니다.

winget install Microsoft.PowerToys

자주 쓰는 모듈

모듈하는 일
FancyZones창을 화면 구역에 자동 정렬
PowerRename파일 일괄 이름 변경(정규식 지원)
Always On Top창을 항상 위에 고정
Text Extractor화면 속 글자를 OCR로 추출
Image Resizer이미지 크기 빠른 조절

이 외에도 ColorPicker(화면 색 추출), Peek(폴더 미리보기), Shortcut Guide(단축키 표시) 등 모듈이 계속 추가되고 있습니다.

실전 활용 순서

처음엔 FancyZones와 PowerRename부터 켜보세요. 창 정렬과 파일 일괄 이름 변경은 매일 쓰게 됩니다. 익숙해지면 Text Extractor(OCR)나 Image Resizer를 추가하세요.

FancyZones: Win+Shift+` → 구역 선택 → 창을 끌어놓기
PowerRename: 탐색기에서 파일 선택 → F2 길게 → 일괄 이름 변경

주의할 점

  • Windows 11 64비트 기준입니다 — 구형 OS나 32비트는 미지원
  • 모듈이 많아 처음엔 기능이 산만해 보일 수 있습니다 — 필요한 것만 켜세요
  • 일부 모듈은 관리자 권한이나 재시작이 필요할 수 있습니다

정리

파워토이즈는 마이크로소프트가 공식으로 유지하는 윈도우 생산성 스위스아미 나이프입니다. 설치 한 번으로 창 정렬·파일 이름 변경·OCR·이미지 조절까지 커버되니, 윈도우 사용자라면 한 번쯤 설치해 볼 가치가 있습니다.
