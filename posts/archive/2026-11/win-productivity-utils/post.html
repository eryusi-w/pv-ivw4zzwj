윈도우를 기본 상태로 쓰면 불편한 게 많습니다. 파일 검색, 스크린샷, 파일 탐색기, 메모장 — 각각 더 나은 대안이 있습니다. 이번엔 실무에서 매일 쓰는 윈도우 생산성 유틸 5개를 골랐습니다.

윈도우 생산성 유틸 5선

도구용도라이선스

Flow Launcher앱 실행·파일 검색 허브MIT

1. Everything — 파일 검색의 표준

이름만 쳐도 전체 드라이브를 순식간에 검색합니다. 윈도우 기본 검색은 인덱싱 때문에 느리지만, Everything은 NTFS 저널을 읽어 거의 실시간입니다. voidtools의 프리웨어로, 설치 후 바탕화면에 띄워두고 단축키 하나로 호출하는 게 일반적입니다.

2. Flow Launcher — 앱·파일·명령 허브

Alt+Space 하나로 앱 실행, 파일 검색, 웹 검색, 플러그인 명령까지 처리합니다. Windows의 PowerToys Run이나 macOS Spotlight 같은 역할입니다. GitHub 스타 약 1.6만, MIT 라이선스로 커뮤니티 플러그인이 풍부합니다.

3. ShareX — 스크린샷·녹화·주석

윈도우 기본 캡처 도구로는 부족할 때 쓰는 표준입니다. 영역 캡처, 전체 화면, 스크롤 캡처, 화면 녹화, OCR, 핀 고정까지 됩니다. GitHub 스타 약 4.1만, GPL-3.0 오픈소스입니다.

4. Files — 윈도우 파일 탐색기 대체

탭 지원, 다크모드, 커뮤니티 테마를 갖춘 모던 파일 탐색기입니다. 윈도우 기본 탐색기의 답답함을 크게 줄여줍니다. GitHub 스타 약 4.7만, MIT 라이선스입니다.

5. NotepadNext — 기능 많은 메모장

윈도우 메모장을 대체하는 오픈소스 에디터입니다. 탭, 다중 언어 구문 강조, 세션 복원, 마크다운 미리보기를 지원합니다. GitHub 스타 약 1.5만, GPL-3.0입니다.

설치 우선순위

전부 한꺼번에 깔 필요는 없습니다. 파일 검색이 불편하면 Everything, 앱 실행이 불편하면 Flow Launcher부터 시작하세요. 둘 다 키보드 중심이라 익숙해지면 마우스 사용이 확 줄어듭니다.

정리

윈도우 생산성은 "기본 기능의 빈틈을 메우는 도구"로 채웁니다. 이번 5개는 모두 무료이고 검증됐으니, 불편을 느끼는 부분부터 하나씩 도입해 보세요.
