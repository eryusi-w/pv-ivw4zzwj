"im not ai 설치방법"을 검색해서 들어오셨다면, 이 글이 딱 맞습니다. AI가 쓴 한글을 사람 글처럼 다듬어주는 im-not-ai를 실제로 설치하고 첫 윤문까지 돌려보는 순서를 정리했습니다.

im-not-ai가 뭔가요

im-not-ai(Humanize KR)는 AI가 작성한 한국어 글에서 번역투·기계적 병렬·AI 특유의 어조를 감지해 사람이 쓴 것처럼 다듬어주는 오픈소스 스킬입니다. GitHub 별 6.5k, MIT 라이선스입니다.

Claude Code, Codex CLI, Gemini CLI, GitHub Copilot CLI 등 여러 에이전트 런타임을 지원합니다. 문장 전체를 새로 쓰는 게 아니라 문제 구간만 수술적으로 고치는 방식입니다.

설치 방법 — Claude Code 사용자

Claude Code를 쓴다면 플러그인 마켓플레이스에서 바로 설치합니다.

/plugin install humanize-korean@im-not-ai

설치가 끝나면 아무 프로젝트 폴더에서나 /humanize-korean 명령으로 윤문을 실행할 수 있습니다.

설치 방법 — Codex·기타 CLI

Codex나 여러 런타임을 함께 쓰려면 저장소를 클론해 설치 스크립트를 실행합니다.

git clone https://github.com/epoko77-ai/im-not-ai.git
cd im-not-ai
./install.sh

install.sh가 설치된 claude/codex를 자동 감지해 전역 심링크를 만듭니다. 한쪽만 설치하려면 --claude-only, --codex-only, --gemini-only 옵션을 붙이면 됩니다.

다른 환경에서 쓰기

환경설치 방법
Claude Code/plugin install humanize-korean@im-not-ai
Codex CLI./install.sh --codex-only → $humanize-korean
Gemini CLIgemini extensions install <repo URL>
Copilot CLIcopilot plugin install humanize-korean@im-not-ai

첫 윤문 실행하기

설치 후에는 윤문할 텍스트를 붙여넣고 /humanize-korean(Claude) 또는 $humanize-korean(Codex)을 실행하면 됩니다.

코드 블록이나 기술 용어는 제외하고 문단만 윤문하도록 지시하는 게 좋습니다. 윤문 결과 하단에는 수정률·등급 같은 HUMANIZE-SUMMARY가 붙어 변경 폭을 확인할 수 있습니다.

주의할 점

  • 윤문은 어투 교정이지 사실 검증이 아닙니다 — 수치·주장은 원문 그대로 유지됩니다
  • 법률·규정 문서처럼 형식이 중요한 글은 사람이 최종 확인하세요
  • 업데이트는 ./update.sh, 제거는 ./uninstall.sh로 관리합니다

정리

Claude Code라면 /plugin install 한 줄, Codex 등은 클론 후 ./install.sh면 끝입니다. 설치 후 /humanize-korean으로 바로 써볼 수 있습니다.
