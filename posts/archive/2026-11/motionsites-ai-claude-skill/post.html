Claude에게 랜딩 페이지를 만들라고 하면 대부분 비슷하게 밋밋한 결과가 나옵니다. claude-skill(MotionSites Web Builder)은 이런 결과를 바꾸도록 설계된 Claude 스킬입니다.

Claude가 수상작 수준의 시네마틱 랜딩 페이지를 만들도록 돕는 스킬로, 예제 프롬프트 40개·미디어 라이브러리·기법 레시피 55개 이상·스크린샷 QA 루프를 포함하며 현재 GitHub 스타 약 2,049개입니다.

핵심 특징 3가지

  • 실제 미디어 활용 — 50개 이상의 시네마틱 히어로 영상, 3D 컷아웃, 이미지를 골라 씁니다.
  • 정밀 스펙 작성 — 코딩 전에 상세한 빌드 명세를 먼저 만들어 품질을 좌우합니다.
  • 자체 검수 루프 — 스크린샷을 찍어 깨진 자산·모바일 오버플로·폰트·영상 재생을 스스로 점검하고 고칩니다.

설치와 빠른 실행

스킬 자체의 코드·지침은 MIT 라이선스이고, 예제 프롬프트와 미디어는 MotionSites의 저작권이므로 만든 사이트에 그대로 써도 되지만 재배포는 안 됩니다.

/plugin marketplace add Motionsites-AI/claude-skill
/plugin install motionsites-web-builder@motionsites

Claude Code에서는 플러그인 명령으로 설치하고, Claude.ai·데스크톱에서는 릴리스의 zip을 스킬로 업로드합니다. 설치 후 "런던의 건축 사진작가 포트폴리오 홈페이지를 만들어 줘"처럼 사이트 제작을 요청하면 스킬이 자동으로 적용됩니다.

실전 활용 시나리오

처음엔 예제 프롬프트 중 마음에 드는 디자인을 골라 그대로 써 보고, 익숙해지면 내 서비스에 맞게 변형합니다.

git clone https://github.com/Motionsites-AI/claude-skill.git
  • 1단계 — 플러그인으로 설치하고 간단한 랜딩 페이지를 요청합니다.
  • 2단계 — 결과물을 열어 스크린샷 QA가 실제로 뭘 고쳤는지 로그를 확인합니다.
  • 3단계 — 원하는 느낌의 예제 프롬프트를 찾아 프롬프트 모드로 변형 지시를 받습니다.
  • 4단계 — Lovable·v0·Bolt에 붙일 프롬프트로도 출력할 수 있습니다.

직접 쓰기 전 알면 좋은 점

자체 검수 루프가 제대로 돌려면 Playwright 설치가 필요합니다(pip install playwright). 미디어 셸프는 MotionSites의 무료 샘플이라, 프리미엄 느낌을 원하면 유료 Unlimited 플랜을 권유하는 구조입니다. 디자인이 화려한 방향이라 깔끔한 기업 문서 사이트에는 과할 수 있습니다.

누구에게 필요한가

랜딩 페이지·포트폴리오·프로덕트 소개 사이트를 빠르게 만들고 싶은 프론트엔드 개발자, 디자이너, 마케터에게 특히 유용합니다. "AI가 만든 사이트는 다 비슷해 보인다"는 문제를 겪은 경우에 맞습니다.

정리

평범한 AI 레이아웃 대신 검증된 디자인 문법과 실제 미디어로 랜딩 페이지를 만들게 하는 스킬입니다. 스크린샷으로 스스로 검수하는 루프가 핵심 차별점입니다.
