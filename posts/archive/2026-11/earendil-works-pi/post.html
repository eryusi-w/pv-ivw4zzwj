여러 LLM을 번갈아 쓰려면 각각의 API를 따로 붙여야 해서 설정이 금방 복잡해집니다. pi는 통합 LLM API와 에이전트 루프, 터미널 UI를 한 툴킷으로 묶은 TypeScript 도구입니다.

다중 LLM 프로바이더 지원, 에이전트 루프, TUI, 코딩 에이전트 CLI를 갖춘 AI 에이전트 툴킷으로, MIT 라이선스에 현재 GitHub 스타 118,846개입니다.

핵심 특징 3가지

  • 통합 LLM API — 여러 프로바이더를 한 인터페이스로 호출합니다.
  • 에이전트 루프 — 작업을 단계별로 쪼개 자동으로 이어갑니다.
  • 터미널 UI — 대화형 인터페이스와 코딩 에이전트 CLI를 제공합니다.

설치와 빠른 실행

npm i -g @earendil/pi

전역 설치 후 터미널에서 pi를 실행하면 TUI가 열립니다. 사용할 LLM 프로바이더의 키를 등록하고 첫 작업을 시켜 봅니다.

실전 활용 시나리오

모델을 하나씩 등록해 두고, 작업별로 가장 잘 맞는 모델을 골라 씁니다.

git clone https://github.com/earendil-works/pi.git
  • 1단계 — npm으로 설치하고 TUI를 실행합니다.
  • 2단계 — 두세 개 프로바이더의 API 키를 등록합니다.
  • 3단계 — 코드 관련 질문을 던져 코딩 에이전트 CLI 동작을 확인합니다.
  • 4단계 — 같은 작업을 다른 모델로 반복해 품질 차이를 비교합니다.

직접 쓰기 전 알면 좋은 점

일부 고급 기능은 문서가 부족할 수 있습니다. 여러 프로바이더를 등록하면 그만큼 키 관리와 비용 관리가 필요하니, 처음에는 쓰는 모델 두세 개로 제한하는 게 좋습니다.

누구에게 필요한가

Node.js/TypeScript 기반 AI 애플리케이션 개발자에게 특히 유용합니다. 터미널에서 AI 코딩 보조와 에이전트 개발을 함께 하고 싶은 경우에 맞습니다.

정리

모델 연동부터 에이전트 루프, 터미널 UI까지를 한 패키지로 묶은 툴킷입니다. 설정이 얕아 시작하기 쉽고, 익숙해지면 용도별로 모델을 나눠 쓰기 좋습니다.
