파일 내용을 확인하려고 더블클릭해서 앱을 켰다가, 확인하고, 다시 닫는 과정이 은근히 시간을 먹습니다. QuickLook은 macOS의 스페이스바 미리보기를 윈도우로 가져온 도구로, 파일을 선택한 상태에서 스페이스바만 누르면 내용을 바로 보여줍니다.

파일을 열지 않고 내용 확인하기

사진 한 장을 보려고 이미지 뷰어를 켜고, PDF를 보려고 뷰어를 켜고 — 이런 반복이 하루에도 몇 번씩 일어납니다. 내용만 잠깐 확인하면 되는 상황에서 무거운 앱을 매번 여는 건 비효율입니다.

QuickLook(Ql-Win/QuickLook)은 이런 "잠깐 보기"를 위한 도구입니다. 파일 탐색기에서 파일을 고르고 스페이스바를 누르면, 별도 앱을 실행하지 않고 바로 미리보기가 뜹니다. 저장소 설명이 "Bring macOS Quick Look feature to Windows"인 이유입니다.

QuickLook이 하는 일

핵심은 단순합니다. 파일을 선택한 상태에서 스페이스바를 누르면 미리보기 창이 열리고, 다시 누르거나 ESC를 누르면 닫힙니다. 윈도우 파일 탐색기뿐 아니라 파일을 여는 대화상자에서도 동작합니다.

GitHub 저장소 기준으로 스타 약 2.6만 개, 포크 약 1,400개 규모의 프로젝트입니다. 라이선스는 GPL-3.0, 언어는 C#이고, 2017년에 시작해 꾸준히 유지보수되고 있습니다. 최근 릴리스는 v4.5.0(2026-04-14)입니다.

README 기준으로 이미지, 동영상, 문서, 코드, 압축 파일, 폰트 등 100여 종 이상의 형식을 지원한다고 안내하고 있고, 플러그인으로 확장할 수 있다고 밝히고 있습니다. 화면은 Fluent Design을 따르며 4K 화면과 터치 조작에도 대응한다고 설명합니다.

설치 방법 고르기

설치는 배포 채널별로 네 갈래입니다. 윈도우 사용자라면 winget이 가장 간단합니다.

winget install QL-Win.QuickLook
winget list --id QL-Win.QuickLook
방법자동 업데이트대화상자 지원비고
Microsoft Store자동미지원보안 샌드박스
인스톨러수동지원포터블 모드 가능
Scoop자동지원Scoop 사용자용
Nightly수동지원최신 개발 빌드

README의 배포 비교표 기준으로, Open/Save 대화상자 지원이 없는 건 Store판뿐입니다. 저장 대화상자 안에서도 스페이스바 미리보기를 쓰고 싶다면 인스톨러·Scoop·Nightly 중 하나를 고르면 됩니다.

지원 형식과 플러그인

README가 안내하는 지원 범위는 꽤 넓습니다.

  • 이미지 — JPEG, PNG, GIF, WebP, RAW 계열
  • 동영상 — MP4, AVI, MKV, MOV
  • 문서 — PDF, Office 문서, 마크다운, EPUB, CBZ
  • 개발 파일 — 코드 구문 강조, JSON·YAML·TOML, ZIP·7Z, 바이너리 hex 뷰
  • 기타 — 오디오, 폰트, SVG·EPS, 자막 파일

여기에 플러그인 구조가 있어서 지원하지 않는 형식도 확장할 수 있습니다. README 기준으로는 .qlplugin 파일을 받아, QuickLook이 실행 중인 상태에서 해당 파일을 선택해 스페이스바를 누르고 Install 버튼을 누른 뒤 재시작하면 설치됩니다. 동작 위치도 파일 탐색기 외에 열기·저장 대화상자, Total Commander 같은 서드파티 파일 매니저, OneDrive·Dropbox 같은 클라우드 저장소까지 포함합니다.

실제로 쓰는 모습

설치하면 QuickLook이 시스템 트레이에 상주하고, 파일 탐색기에서 바로 동작합니다. 파일을 클릭해 선택하고 스페이스바를 누르면 미리보기가 뜨고, 스페이스바나 ESC로 닫습니다. 위·아래 화살표 키로 여러 파일을 넘겨보는 것도 README가 안내하는 사용법입니다.

자주 쓰는 파일 형식이 미리보기에 안 뜨면 설정이나 플러그인에서 해당 형식을 켜면 됩니다. README가 강조하는 포인트는 "설치하고 잊어도 되는" 수준의 가벼움입니다.

알아 둘 한계

몇 가지는 미리 알아두면 좋습니다. Microsoft Store 버전은 Open/Save 대화상자 지원이 제한적이라고 README가 명시합니다. 이 대화상자 안에서도 미리보기를 쓰려면 인스톨러나 포터블 버전이 필요합니다.

GPL-3.0 라이선스라 소스가 공개돼 있고, 커뮤니티 플러그인 생태계가 있지만, 상용 수준의 지원 계약이 있는 제품은 아닙니다. 그래도 2017년부터 유지된 프로젝트이고 스타 규모도 작지 않아, 윈도우 생산성 도구로는 검증된 선택지입니다.

정리

QuickLook은 "파일을 여는 행위" 자체를 줄여주는 도구입니다. 스페이스바 하나로 이미지·문서·코드·동영상까지 훑어볼 수 있으니, 파일이 많은 폴더를 자주 오가는 환경에서 체감이 큽니다. winget 한 줄이면 끝나니 오늘 한 번 설치해서 스페이스바를 눌러보세요.
