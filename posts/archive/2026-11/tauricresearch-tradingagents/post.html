트레이딩 전략을 코드로 짜고 백테스트하려면 데이터 수집부터 시뮬레이션까지 직접 만들어야 합니다. TradingAgents는 이 과정을 LLM 기반 멀티 에이전트로 자동화하는 프레임워크입니다.

AI 에이전트로 자동화된 트레이딩 전략을 실행·백테스트하는 오픈소스 프레임워크로, Apache-2.0 라이선스에 현재 GitHub 스타 120,138개입니다.

핵심 특징 3가지

  • 멀티 에이전트 구조 — 분석·판단·실행 역할을 나눈 에이전트들이 협업합니다.
  • 백테스팅 엔진 — 과거 데이터로 전략을 검증할 수 있습니다.
  • 실시간 데이터 연동 — 시장 데이터 스트리밍과 거래소 연동을 지원합니다.

설치와 빠른 실행

git clone https://github.com/TauricResearch/TradingAgents.git

저장소를 클론한 뒤 README의 환경 설정을 따라 의존성을 설치하고, 사용할 LLM과 데이터 소스를 설정합니다.

실전 활용 시나리오

실전 투입이 아니라 백테스트와 모의 운용부터 시작합니다.

  • 1단계 — 저장소를 클론하고 환경 변수에 LLM 키를 설정합니다.
  • 2단계 — 관심 종목과 기간을 정해 백테스트를 실행합니다.
  • 3단계 — 에이전트별 판단 로그를 보며 전략이 어디서 갈리는지 분석합니다.
  • 4단계 — 결과가 나쁘면 규칙을 수정하고 다시 백테스트합니다.

직접 쓰기 전 알면 좋은 점

초기 개발 단계라 문서가 부족하고 안정성 검증이 더 필요합니다. 자동 매매를 실제 계좌에 연결하기 전에 반드시 모의 환경과 백테스트로 충분히 검증해야 하며, LLM 판단은 재현성이 낮아 같은 조건에서도 결과가 달라질 수 있습니다.

누구에게 필요한가

금융 엔지니어, 퀀트 개발자, AI 연구자에게 특히 유용합니다. 시장 데이터로 알고리즘 트레이딩을 빠르게 프로토타이핑해 보고 싶은 경우에 맞습니다.

정리

LLM 에이전트로 트레이딩 전략을 실험하는 프레임워크입니다. 초기 단계인 만큼 실험 도구로 쓰고, 실전 판단은 별도의 검증 과정이 필요합니다.
