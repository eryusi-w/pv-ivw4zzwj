AI가 쓴 코드를 영상으로 렌더링 (raea)

#AI도구#오픈소스#모션그래픽#영상편집#3D#게임개발#TypeScript#에이전트#렌더링#Rust

AI에게 영상을 만들어 달라고 하면 코드가 나옵니다. 그 코드를 화면으로 보려면 렌더링 도구를 다시 붙여야 하고, 여기서 작업이 한 번 끊깁니다.

raea는 그 끊김을 없애려는 엔진입니다. React와 TypeScript로 쓴 코드를 자기 GPU에서 렌더링해서 영상, 모션 그래픽, 3D, 게임으로 만들어 줍니다. Rust와 Bevy로 만들었고 macOS·리눅스·윈도우에서 돕니다.

핵심 특징 3가지

README가 내세우는 기능은 세 갈래입니다. 영상, 게임, 그리고 에이전트 연결입니다.

  • 영상과 모션 그래픽 — 레이아웃, 텍스트, Tailwind, SVG, 애니메이션을 GPU에서 합성하고, 가능한 기기에서는 하드웨어 인코더로 뽑습니다.
  • 게임 — 입력, 물리, 사운드, 3D를 raea play로 바로 실행하고, raea export-game으로 독립 프로그램으로 내보냅니다.
  • 에이전트 연결 — 설치할 때 raea의 에이전트 스킬을 ~/.claude/skills에 넣습니다. Claude Code처럼 그 폴더를 읽는 에이전트가 raea 작업을 쓰고, 렌더하고, 확인하는 방법을 알게 됩니다.

엔진은 무료이고 계정도 필요 없습니다. 코드가 React와 TypeScript라서 AI가 이미 잘 쓰는 언어를 그대로 씁니다.

설치와 빠른 실행

윈도우 10·11에서는 PowerShell에서 한 줄입니다. 설치 스크립트가 raea 명령을 ~\.raea에 두고 PATH에 추가합니다.

irm https://raea.io/install.ps1 | iex

맥과 리눅스는 같은 설치 스크립트의 셸 버전을 씁니다. 명령은 ~/.raea에 설치하고 ~/.local/bin에 연결합니다. 다시 실행하면 업데이트가 됩니다.

실전 활용 시나리오

소스에서 직접 빌드할 때의 순서는 README에 그대로 적혀 있습니다. Rust, bun, CMake가 필요합니다.

git clone https://github.com/shinyobjectz/raea && cd raea
cargo build --release -p raea-cli --no-default-features
for d in sdk/raea sdk/react/js sdk/react/tw; do (cd $d && bun install); done
target/release/raea render sdk/react/bench/games/pong/edit.tsx -o pong.mp4
  • 1단계 — 설치 스크립트로 CLI와 에이전트 스킬을 함께 넣습니다. 빌드부터 하려면 위 명령을 따릅니다.
  • 2단계 — 에이전트에게 만들 것을 말하고 React 컴포지션 파일을 받습니다.
  • 3단계 — raea render로 MP4를 뽑습니다. 저장소의 pong 예제가 가장 짧은 출발점입니다.
  • 4단계 — 영상이 마음에 들면 raea check로 자막 잘림과 정지 구간을 먼저 걸러 냅니다.

렌더 전에 걸러 주는 검사

이 엔진에서 눈에 띄는 부분은 렌더링 자체보다 검사입니다. 영상을 만든 사람이 놓치기 쉬운 것을 명령 하나로 잡습니다.

  • raea check — 잘린 텍스트, 낮은 대비, 안전 영역 침범, 화면 멈춤, 음량 문제를 시청 전에 잡아냅니다.
  • raea cut — 영상에서 말하는 내용을 기준으로 장면을 잘라 냅니다.
  • raea play / export-game — 게임을 실시간으로 실행해 보고, 별도 프로그램으로 내보냅니다.

숏폼을 자주 만든다면 이 검사가 실질적인 시간을 줄여 줍니다. 렌더를 다 돌리고 나서 잘린 글자를 발견하는 일이 줄어들기 때문입니다.

직접 쓰기 전 알면 좋은 점

  • 라이선스가 일반 오픈소스와 다릅니다 — FSL-1.1-ALv2입니다. 쓰고 고치고 배포할 수 있지만 raea와 경쟁하는 제품에는 쓸 수 없습니다. 각 버전은 공개 2년 뒤 Apache-2.0으로 바뀝니다.
  • 그래픽 환경을 탑니다 — 윈도우는 Microsoft Visual C++ 재배포 패키지(x64)와 DirectX 12 또는 Vulkan 드라이버가 필요합니다.
  • 아직 초기입니다 — 저장소가 2026년 10월에 만들어졌고 커밋은 516개입니다. 문서가 얇은 부분을 만날 수 있습니다.
  • 에이전트 폴더를 건드립니다 — 설치할 때 ~/.claude/skills에 스킬을 넣습니다. 기존 스킬과 섞이는 게 싫다면 설치 후 폴더를 확인하세요.
"AI가 만든 결과물을 눈으로 확인하는 데 걸리는 시간"이 이 도구가 줄이려는 값입니다. 렌더가 재생 속도보다 빠르다는 말이 그 뜻입니다.

누구에게 필요한가

이미 에이전트에게 코드를 맡기고 있는 사람에게 맞습니다.

  • Claude Code로 만든 결과물을 영상으로 보고 싶은 개발자
  • 모션 그래픽을 코드로 관리하고 싶은 크리에이터
  • 작은 3D·게임 프로토타입을 빠르게 돌려 보고 싶은 팀

반대로 완성된 편집 도구의 타임라인과 효과 패널이 필요하다면 기존 영상 편집 프로그램이 낫습니다. 이 엔진은 코드가 중심입니다.

정리

raea는 AI가 쓴 React·TypeScript 코드를 로컬 GPU에서 바로 영상과 게임으로 바꾸는 엔진입니다. 설치 한 줄로 CLI와 에이전트 스킬이 함께 들어옵니다.

먼저 저장소의 pong 예제를 렌더해 보세요. 결과가 나오면 그때 raea check를 습관으로 붙이는 순서가 좋습니다.
