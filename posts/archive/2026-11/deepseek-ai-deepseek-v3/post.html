671B 파라미터 오픈 모델을 직접 돌리려면 보통 대규모 GPU 클러스터가 필요하다고 알려져 있습니다. DeepSeek-V3는 이 장벽을 낮춘 오픈소스 플래그십 LLM입니다.

고효율 MoE 아키텍처와 강력한 추론 능력을 갖춘 오픈소스 LLM으로, MIT 라이선스에 현재 GitHub 스타 104,815개입니다.

핵심 특징 3가지

  • 671B MoE 구조 — 전문가 혼합 구조로 추론 비용을 크게 낮췄습니다.
  • 강력한 범용 성능 — 코드·수학·다국어 작업에서 상위권 성능을 냅니다.
  • 다양한 추론 경로 — Hugging Face, vLLM, Ollama 등 여러 백엔드에서 불러 쓸 수 있습니다.

설치와 빠른 실행

모델 가중치 저장소라 pip 설치는 없습니다. Hugging Face나 Ollama 같은 추론 도구로 불러옵니다.

ollama run deepseek-v3

양자화된 버전은 개인 GPU에서도 시도할 수 있지만, 풀 프리시전은 H100 여러 장급이 필요합니다. 처음에는 호스팅 API나 양자화 버전으로 성능을 확인하는 게 현실적입니다.

로컬 서버가 없다면 API로 먼저 쓰고, 인프라가 생기면 자체 서빙으로 옮깁니다.

git clone https://github.com/deepseek-ai/DeepSeek-V3.git
  • 1단계 — Hugging Face 또는 Ollama로 모델을 내려받습니다.
  • 2단계 — 샘플 프롬프트로 코드·추론 품질을 직접 확인합니다.
  • 3단계 — vLLM 등으로 서빙해 API 형태로 붙입니다.
  • 4단계 — 도메인 데이터로 파인튜닝하거나 양자화를 적용합니다.

직접 쓰기 전 알면 좋은 점

MIT 라이선스라 상용 배포가 자유롭지만, 풀 모델을 직접 서빙하려면 GPU 비용이 큽니다. 양자화·오프로딩 설정이 까다로워 처음에는 호스팅 API로 품질을 먼저 검증하는 편이 낫습니다.

누구에게 필요한가

LLM 연구원, 백엔드/AI 엔지니어, 온프레미스 배포가 필요한 기업 개발팀에게 특히 유용합니다. 프라이빗 환경에서 최상위급 오픈 모델을 실험하고 싶은 경우에 맞습니다.

정리

상용 무료 라이선스와 최상위 성능, 다양한 추론 생태계를 갖춘 오픈 LLM입니다. 인프라가 없어도 양자화나 API로 충분히 써 볼 수 있습니다.
