엑셀 함수가 안 먹힐 때, VLOOKUP 오류가 날 때 ChatGPT에 물어보면 됩니다. "엑셀 함수 짜줘"가 아니라 구조화된 프롬프트를 주면 바로 쓸 수 있는 수식이 나옵니다.

왜 그냥 물어보면 안 되나

"엑셀 함수 만들어줘"라고만 하면 엉뚱한 답이 옵니다. 어떤 데이터가 있고, 뭘 찾고 싶은지, 엑셀 버전이 뭔지를 같이 줘야 정확한 수식이 나옵니다.

복사해서 쓰는 프롬프트 템플릿

엑셀 수식을 만들어줘.

상황: [예: A열에 사번, B열에 이름, 다른 시트에 급여표가 있음]
하고 싶은 것: [예: 사번으로 이름 찾아오기]
엑셀 버전: [예: 365 또는 2019]
참고: VLOOKUP 오류가 나서 INDEX-MATCH로 바꾸고 싶음

핵심은 데이터 구조와 목적을 구체적으로 쓰는 겁니다.

템플릿을 실제로 채워 넣으면 이렇게 됩니다.

엑셀 수식을 만들어줘.

상황: Sheet1 A열=사원ID, B열=이름 / Sheet2 A열=사원ID, B열=부서명
하고 싶은 것: Sheet1 C열에 사원ID로 부서명 가져오기, 없으면 '정보 없음' 표시
엑셀 버전: 365

자주 쓰는 활용 예시

  • VLOOKUP 오류 → INDEX-MATCH 또는 XLOOKUP으로 교체 요청
  • 조건 여러 개 걸기 → SUMIFS·COUNTIFS 조합 요청
  • 날짜 계산 → DATEDIF·NETWORKDAYS로 근무일수 계산
  • 텍스트 정리 → TRIM·SUBSTITUTE·TEXTJOIN 조합

결과 검증 — 반드시 직접 테스트

AI가 준 수식을 그대로 믿으면 안 됩니다. 엑셀 버전 차이(특히 XLOOKUP은 365/2021+ 전용), 절대참조($) 누락, 범위 오류가 흔합니다.

작은 샘플 데이터로 먼저 테스트하고, 오류 메시지를 다시 AI에게 보여주며 고치는 게 가장 빠릅니다.

주의할 점

  • 회사 기밀 데이터는 개인 ChatGPT에 넣지 마세요 — 회사 계정·엔터프라이즈 버전 사용 권장
  • 엑셀 2019 이하는 XLOOKUP·FILTER 같은 새 함수가 없습니다 — 버전을 꼭 명시하세요
  • VBA는 별도 요청 — "VBA 매크로"라고 명시해야 매크로 코드가 나옵니다

정리

ChatGPT에 엑셀 함수를 물어볼 때는 "상황 + 목적 + 버전"을 같이 쓰세요. 결과는 샘플로 검증하고, 기밀 데이터는 넣지 않는 게 원칙입니다.
