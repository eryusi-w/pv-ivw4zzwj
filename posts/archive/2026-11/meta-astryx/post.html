문제 제기

AI가 코드를 잘 쓰는 시대가 되면서 UI도 사람이 아니라 에이전트가 만지는 경우가 늘었습니다. Meta가 공개한 astryx는 그런 흐름에 맞춘 디자인 시스템입니다.

무엇인가

Meta가 공개한 커스터마이징 가능한 디자인 시스템입니다. 완전히 테마를 바꿀 수 있고 코딩 에이전트가 바로 쓸 수 있도록 설계됐습니다. 현재 GitHub 스타 24,099개, 주 언어는 TypeScript입니다.

핵심 기능

  • 테마를 교체해 제품 고유의 디자인 언어 구현
  • 코딩 에이전트 연동을 전제로 한 구조
  • React 19 이상 환경에서 동작
  • 전용 CLI 제공

설치와 첫 실행

npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex
