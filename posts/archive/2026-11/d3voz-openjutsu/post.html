문제 제기

영상 속 인물을 다른 사람으로 바꾸고 싶을 때 클라우드 서비스는 비용과 프라이버시가 걸립니다. 로컬에서 돌아가는 openjutsu를 살펴봅니다.

무엇인가

영상 속 인물이나 사물을 사진 한 장으로 교체하는 로컬 ComfyUI 기반 도구입니다. 클라우드형 Higgsfield Genjutsu의 오픈소스 대안 역할을 합니다. 현재 GitHub 스타 2,173개, 주 언어는 TypeScript입니다.

핵심 기능

  • 영상과 캐릭터 사진을 넣으면 원클릭으로 인물 스왑
  • ComfyUI 커스텀 노드로 설치해 기존 워크플로와 결합
  • Qwen3-VL 등 비전 모델이 프롬프트를 자동 작성
  • FLUX Klein 리라이팅으로 자연스러운 조명 처리

설치와 첫 실행

ComfyUI 0.41.2 이상과 NVIDIA GPU가 필요하고, 영상 모델(H3)과 트래킹·비전 모델까지 ComfyUI에 준비해야 합니다. 저장소의 custom_nodes 목록에 있는 팩들을 ComfyUI/custom_nodes에 설치한 뒤 ComfyUI를 재시작합니다. Windows는 start_openjutsu.bat를 더블클릭하면 프록시와 앱이 한 번에 준비됩니다.

기본 사용법

앱이 열리면 영상과 캐릭터 사진을 올리고 Generate를 누릅니다. 카메라·컷·모션은 원본을 유지한 채 인물만 교체됩니다. 소스에서 직접 실행하려면:

git clone https://github.com/D3voz/openjutsu.git
