문제 제기

3D나 VFX 작업은 GUI 없이는 에이전트가 손대기 어렵다고 여겨졌습니다. vork는 그 전제를 뒤집는 실험적 엔진입니다.

무엇인가

에이전트가 사용하도록 설계된 headless 3D·VFX 엔진입니다. 리서치 프리뷰 단계로, 카메라·조명·장면을 텍스트로 기술해 렌더링합니다. 현재 GitHub 스타 1,377개, 주 언어는 Rust입니다.

핵심 기능

  • 헤드리스 환경에서 3D·VFX 렌더링
  • 카메라·조명·소재를 텍스트로 기술
  • vork init으로 프로젝트 생성 후 프리뷰 렌더
  • NVIDIA GPU와 Vulkan 드라이버 필요

설치와 첫 실행

GitHub Releases에서 Linux·Windows·Mac용 바이너리 패키지를 받거나, Ubuntu에서는 install.sh 한 줄로 설치합니다. NVIDIA GPU와 하드웨어 레이 트레이싱 Vulkan 드라이버가 필요합니다.

curl -fL https://github.com/voyager-so/vork/releases/latest/download/install.sh | sh

기본 사용법

vork init으로 프로젝트를 만들고 scene.json에 카메라·조명·장면을 텍스트로 기술한 뒤 렌더링합니다. 에이전트라면 렌더 결과 PNG를 다시 보고 장면을 수정하는 루프를 돌립니다.

vork init my-shot
cd my-shot
vork render scene.json --out render.png

추천 이유

누구에게 필요한가

3D·영상 결과물을 에이전트에게 생성시키는 실험적 프로젝트에게 특히 유용합니다.

정리

vork는 에이전트가 사용하도록 설계된 headless 3D·VFX 엔진입니다. 리서치 프리뷰 단계로, 카메라·조명·장면을 텍스트로 기술해 렌더링합니다.입니다. 작은 작업 하나부터 붙여 보는 것을 권합니다.
