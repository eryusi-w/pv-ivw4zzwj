문제 제기

AI 코딩 도구를 쓰다 보면 모델 비용이 은근히 커집니다. 감사는 비싼 모델이 하고 실행은 싼 모델이 하는 improve의 방식을 정리했습니다.

무엇인가

코드베이스를 감사해 다른 에이전트가 실행할 구현 계획을 작성하는 에이전트 스킬입니다. 비싼 모델은 판단에만 쓰고 실행은 저렴한 모델에 맡기는 비용 분리 구조가 핵심입니다.

핵심 기능

  • 고성능 모델이 코드베이스를 감사하고 가치 있는 작업을 선별
  • 실행용 계획서를 마크다운으로 작성해 어떤 에이전트든 이어받기 가능
  • Agent Skills 형식이라 npx 한 줄로 설치
  • 스스로 구현하지 않고 계획만 만들도록 설계

설치와 첫 실행

npx skills add shadcn/improve

현재 릴리즈나 설치 지침이 없어 설치할 수 없습니다; 프로젝트 업데이트를 기다려야 합니다.

기본 사용법

git clone https://github.com/shadcn/improve.git

대규모 코드베이스를 관리하는 개발자들이 AI를 활용해 품질을 높이면서 비용을 절감할 때

한계와 주의

문서 부족, 릴리즈 없음, 높은 복잡도로 인한 초기 사용 장벽

추천 이유

  • 모델 비용을 '판단'과 '실행' 단계로 나눠 쓰는 실용적인 구조
  • shadcn이 만든 검증된 에이전트 스킬
  • 계획이 일반 마크다운이라 특정 도구에 종속되지 않음
  • 설치가 npx skills add 한 줄로 끝남

누구에게 필요한가

AI 코딩 에이전트로 대규모 코드베이스를 다루는 개발자에게 특히 유용합니다.
