Ollama — 개발자와 자동화向き

터미널 명령 하나로 모델을 받고 실행하는 런타임입니다. Kimi, GLM, DeepSeek, Qwen, Gemma 같은 최신 모델을 바로 지원하고, OpenAI 호환 API를 로컬에 열어주기 때문에 기존 앱에 붙이기 가장 쉽습니다. 스크립트와 파이프라인에 넣을 때 사실상 표준입니다.

ollama run qwen3:8b

LM Studio — GUI로 시작하는 분向き

설치 후 모델을 검색해 다운로드하고 채팅까지 GUI에서 끝내는 완성형 앱입니다. Hugging Face 모델을 바로 쓸 수 있고 대화 UI가 친절합니다. 클로즈드 소스지만 개인 사용은 무료이고, 회사 도입은 별도 라이선스가 필요합니다.

Jan — ChatGPT처럼 쓰는 오픈소스

"100% 오프라인에서 돌아가는 ChatGPT 대안"을 표방하는 앱입니다. 모델을 내려받아 바로 대화할 수 있고, 오픈소스라 직접 수정하거나 셀프호스팅할 수 있습니다. 개발자 도구보다는 일반 사용자에게 ChatGPT 경험을 주는 데 초점이 있습니다.

어떤 걸 골라야 할까

  • 앱·스크립트에 로컬 LLM을 붙일 계획 → Ollama
  • GUI로 모델을 골라 채팅만 즐길 계획 → LM Studio 또는 Jan
  • 오픈소스를 원칙으로 삼는 팀 → Ollama 또는 Jan

공통으로 모델 파일은 비슷하게 무거우니, GPU가 없다면 3B~8B급 소형 모델부터 시작하세요. 셋 다 같은 GGUF 계열 모델을 쓰는 경우가 많아 처음엔 아무거나 써 보고 옮겨도 됩니다.

정리

로컬 LLM 도구는 "런타임+API"(Ollama), "완성형 채팅 앱"(LM Studio·Jan)으로 나뉩니다. 자동화·개발 연동이 목적이면 Ollama, 그냥 채팅이 목적이면 LM Studio나 Jan이 편합니다.

참고: github.com/ollama/ollama (MIT), github.com/janhq/jan (오픈소스), lmstudio.ai (개인 무료)
