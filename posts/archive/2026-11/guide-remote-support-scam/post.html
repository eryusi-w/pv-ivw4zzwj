"검찰입니다. 범죄 혐의가 있습니다."라는 전화와 함께 원격제어 프로그램 설치를 요구받는 사기가 있습니다. 가족·지인 PC를 노리는 수법입니다. 구별법과 대처법을 정리했습니다.

원격지원 사기란

사기꾼이 공공기관·금융기관을 사칭해 전화한 뒤, 피해자에게 원격제어 프로그램(AnyDesk, TeamViewer 등)을 설치하게 합니다. 원격으로 PC를 제어해 금융정보를 탈취하거나, 피해자 계좌에서 돈을 이체합니다. 최근에는 가족을 사칭해 "컴퓨터가 고장났다"며 도움을 요청하는 수법도 있습니다.

수법의 전형적 패턴

  • 검찰·경찰·금융감독원을 사칭해 범죄·체납·수사를 언급
  • "보안프로그램", "보안점검" 명목으로 원격제어 앱 설치 요구
  • 설치 후 화면을 보며 금융앱·비밀번호를 입력하게 유도
  • "계좌를 안전하게 보호해준다"며 이체를 요구
  • 가족 사칭 — "엄마 컴퓨터 이상해, 이것 좀 봐줘"

절대 해서는 안 되는 것

전화로 아래를 요구받으면 무조건 사기입니다.

  • 원격제어 프로그램 설치
  • 보안프로그램·백신 설치 요구 (전화로)
  • 화면을 보며 비밀번호·계좌번호 입력 유도
  • "안전하게 보호" 명목의 이체 요구

어떤 공공기관도 전화로 원격 제어를 요구하지 않습니다.

의심스러울 때 대처법

원격제어를 요구하는 전화를 받으면:

1. 전화를 끊는다
2. 상대가 주장하는 기관의 공식 번호로 직접 확인
   (검찰: 각 지방검찰청 / 경찰: 112 / 금융: 각사 고객센터)
3. 가족에게 전화해서 "정말 그런 전화 받았어?" 확인
4. 의심되면 112에 신고

이미 당했을 때

원격제어를 허용했거나 금융정보를 입력했다면 즉시 대응하세요.

  • 금융앱·인터넷뱅킹 접속 차단
  • 비밀번호·OTP·공동인증서 비밀번호 즉시 변경
  • 금융회사에 연락해 지급정지·계좌 잠금 요청
  • PC에 설치된 원격제어 프로그램 삭제
  • 경찰청 112에 신고

가족 PC 보호 설정

고령층 가족을 위한 예방 설정입니다.

  • 원격제어 프로그램(AnyDesk·TeamViewer 등)이 기본 설치돼 있는지 확인
  • 금융앱에 공동인증서·간편비밀번호 외 추가 인증 설정
  • 이체 한도 설정으로 피해 규모 제한
  • 의심 전화는 끊고 공식 번호로 확인하라고 당부

정리

원격지원 사기는 "도와주겠다"는 명목으로 PC를 장악하는 수법입니다. 전화로 원격제어 설치를 요구하면 무조건 사기입니다. 의심되면 끊고 공식 채널로 확인하세요.
