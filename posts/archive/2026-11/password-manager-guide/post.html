"비밀번호를 기억 못 하겠다"는 이유로 같은 비밀번호를 쓰거나 메모장에 적어두는 경우가 많습니다. 비밀번호 관리자 하나면 이 문제를 한 번에 해결할 수 있습니다.

비밀번호 관리자가 뭔가요

모든 계정의 비밀번호를 하나의 암호로 잠가두고, 사이트에 접속할 때 자동으로 채워주는 도구입니다. 마스터 비밀번호 하나만 기억하면 되고, 각 사이트마다 강력한 비밀번호를 따로 쓸 수 있습니다.

왜 필요한가

같은 비밀번호를 여러 사이트에 쓰면 한 곳이 뚫렸을 때 전부 위험합니다. 비밀번호 관리는 사이트마다 무작위 비밀번호를 자동 생성하고, 유출된 비밀번호를 알려주며, 2단계 인증까지 한 곳에서 관리하게 해줍니다.

Bitwarden 시작하기

오픈소스로 GitHub 스타가 clients 1.4만·server 2만 개 수준이고, 개인 무료 플랜으로도 충분합니다. 브라우저 확장과 모바일 앱을 깔고 계정을 만들면 됩니다.

1. bitwarden.com에서 무료 계정 생성
2. 브라우저 확장 설치 (Chrome·Edge·Firefox)
3. 마스터 비밀번호 설정 — 이건 절대 잊으면 안 됨
4. 기존 비밀번호 가져오기 또는 하나씩 등록

주의할 점

  • 마스터 비밀번호를 잊으면 복구 불가 — 별도 안전한 곳에 백업
  • 무료 플랜은 기기 2대 제한이 있을 수 있으니 확인
  • 비밀번호 관리자 자체가 해킹당하면 끝 — 2FA 필수

정리

비밀번호 관리는 "한 번 설정하면 평생 쓰는" 투자입니다. Bitwarden 무료 플랜으로 시작해서, 익숙해지면 1Password 같은 유료로 옮겨도 됩니다.
