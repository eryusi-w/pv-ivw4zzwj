AI 코딩 에이전트가 만든 코드는 동작은 하는데 복잡도가 폭발하기 쉽습니다. ub-mode는 AI 에이전트에 Robert C. Martin(Uncle Bob)의 엔지니어링 원칙을 강제하는 스킬 파일입니다.

AI 에이전트가 코드를 작성·수정할 때 소프트웨어 엔지니어링 원칙을 적용하고, 결정론적 품질 게이트로 복잡도·중복·테스트 커버리지를 검증하는 도구로, MIT 라이선스에 현재 GitHub 스타 7,217개입니다.

핵심 특징 3가지

  • 엔지니어링 원칙 스킬 — SKILL.md 형태로 에이전트에게 원칙을 주입합니다.
  • CRAP 점수 검증 — 함수 복잡도와 테스트 커버리지를 자동으로 측정합니다.
  • 중복·변이 테스트 — 구조적 중복 탐지와 테스트 품질 검증을 지원합니다.

설치와 빠른 실행

npx skills add unclebob/ub-mode

Claude Code·Codex 같은 에이전트의 스킬 디렉토리에 설치하면, 이후 코드 작업 시 원칙이 자동 적용됩니다.

실전 활용 시나리오

설치 후 평소처럼 에이전트에게 코드를 시키되, 결과 코드의 구조와 테스트를 확인하는 습관을 붙입니다.

  • 1단계 — npx로 스킬을 설치하고 에이전트가 인식하는지 확인합니다.
  • 2단계 — 작은 리팩터링 작업을 시켜 생성 코드의 함수 길이와 복잡도를 봅니다.
  • 3단계 — CRAP 점수·중복 검사 결과를 보고 위반 부분을 지적합니다.
  • 4단계 — 테스트가 부족하면 테스트 작성을 요구해 커버리지를 올립니다.

직접 쓰기 전 알면 좋은 점

품질 게이트가 결정론적이라도 원칙 적용이 모든 코드베이스에 과할 수 있습니다. 급한 실험 코드나 프로토타입에는 오히려 속도를 떨어뜨릴 수 있으니, 유지보수할 코드에 집중해 쓰는 게 좋습니다.

누구에게 필요한가

AI 코딩 에이전트로 장기 유지보수할 코드를 만드는 개발자에게 특히 유용합니다. 에이전트가 만든 코드의 품질이 들쭉날쭉한 게 불만인 경우에 맞습니다.

정리

에이전트에게 "잘 짜라"가 아니라 원칙과 검증 도구를 주는 접근입니다. 생성 속도보다 유지보수 품질을 우선하는 팀에 잘 맞습니다.
