윈도우를 쓰다 보면 "이거 단축키 없나?" 싶은 순간이 많습니다. 마우스로 여러 번 클릭하는 대신 단축키를 알면 작업이 훨씬 빠릅니다. 자주 쓰는 것만 정리했습니다.

가장 많이 쓰는 단축키

단축키기능
Ctrl+C / Ctrl+X / Ctrl+V복사 / 잘라내기 / 붙여넣기
Ctrl+Z / Ctrl+Y실행 취소 / 다시 실행
Alt+Tab창 전환
Win+E파일 탐색기 열기
Win+D바탕화면 보기
Win+L화면 잠금
Win+V클립보드 기록 보기
Ctrl+Shift+Esc작업 관리자
Win+PrtScn전체 화면 캡처

탐색기에서 유용한 것

  • Ctrl+L: 주소창에 바로 입력
  • F2: 파일 이름 변경
  • Shift+Delete: 휴지통 안 거치고 삭제
  • Ctrl+Shift+N: 새 폴더 만들기
  • Alt+위 화살표: 상위 폴더로

창 관리 단축키

  • Win+← / →: 창을 화면 절반에 배치
  • Win+↑ / ↓: 창 최대화 / 최소화
  • Win+Tab: 가상 데스크톱·작업 보기
  • Alt+F4: 창 닫기

텍스트 편집 공통

  • Ctrl+A: 전체 선택
  • Ctrl+Home / Ctrl+End: 문서 처음/끝으로
  • Shift+방향키: 텍스트 선택
  • Ctrl+F: 찾기

외우는 팁

처음부터 다 외우려 하지 마세요. 자주 하는 작업 3~4개부터 익히면 됩니다. Ctrl+S(저장), Alt+Tab(창 전환), Win+E(탐색기), Win+L(잠금) 이 네 개만으로도 충분히 편해집니다.

정리

윈도우 단축키는 "자주 쓰는 것부터"가 핵심입니다. 이번 주에 Ctrl+S·Alt+Tab·Win+E·Win+L 네 개만 익혀보세요. 익숙해지면 나머지도 자연스럽게 쓰게 됩니다.
