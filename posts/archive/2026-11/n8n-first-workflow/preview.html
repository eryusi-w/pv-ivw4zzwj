n8n 첫 자동화 만들기, 워크플로우 기초 가이드

#n8n#자동화#워크플로우#업무자동화#노코드#오픈소스#개발도구#생산성#API#초보

"n8n 업무자동화"를 검색했다면, 이 글이 시작점입니다. n8n은 코딩 없이 워크플로우를 만들어 반복 작업을 자동화하는 도구입니다. 첫 자동화를 만드는 순서를 정리했습니다.

n8n이 뭔가요

n8n은 노드(작업 단위)를 연결해 자동화 흐름을 만드는 오픈소스 워크플로우 도구입니다. Zapier 같은 유료 서비스와 달리 셀프호스팅이 가능하고, 코드를 조금씩 넣을 수도 있습니다.

예를 들어 "매일 아침 RSS를 읽어 요약하고 슬랙에 보내기" 같은 흐름을 노드 연결로 만들 수 있습니다.

설치 방법 — 클라우드 vs 셀프호스팅

n8n은 두 가지 방식으로 쓸 수 있습니다.

  • n8n Cloud — 가입만 하면 바로 사용, 무료 티어 있음
  • 셀프호스팅 — Docker로 내 서버에 설치, 데이터가 내 환경에 남음

처음 시작할 때는 클라우드가 빠릅니다. 셀프호스팅은 Docker 명령으로 설치합니다.

docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n

설치 후 브라우저에서 localhost:5678로 접속하면 됩니다.

첫 워크플로우 만들기 — 기본 구조

모든 n8n 워크플로우는 세 부분으로 나뉩니다.

  • Trigger — 언제 시작할지 (수동·스케줄·웹훅)
  • 노드 — 실제 작업 (API 호출·데이터 변환·알림)
  • 연결선 — 데이터가 흐르는 순서

가장 간단한 예: "매일 아침 날씨 API 호출 → 슬랙으로 전송"은 Trigger(Schedule) + HTTP Request + Slack 노드 3개면 됩니다.

첫 실습 — 웹훅으로 데이터 받기

가장 이해하기 쉬운 첫 워크플로우는 웹훅입니다.

1. Webhook 노드 추가 → "Listen for test event" 선택
2. n8n이 URL 생성 → 테스트 요청 보내기
3. 받은 데이터를 확인 → 다음 노드로 연결
4. "Execute workflow"로 실제 실행

웹훅은 외부 서비스(GitHub·폼·다른 앱)가 n8n으로 데이터를 보내는 입구입니다.

자주 쓰는 노드 예시

노드용도
Schedule Trigger정해진 시간에 자동 실행
HTTP Request외부 API 호출
Slack/Gmail알림·메일 발송
Set/Code데이터 가공·변환

주의할 점

  • 처음엔 간단한 것부터 — 트리거 1개 + 노드 2~3개로 시작하세요
  • 자격 증명(API 키)은 Credentials에 따로 저장됩니다
  • 셀프호스팅 시 백업은 .n8n 폴더를 주기적으로 복사

정리

n8n은 트리거→노드→연결의 흐름으로 자동화를 만듭니다. 클라우드로 시작해 웹훅 하나부터 만들어보세요. 익숙해지면 스케줄·API 연동으로 확장하면 됩니다.

참고: n8n 공식 문서(n8n.io)와 Docker Hub 기준입니다.
