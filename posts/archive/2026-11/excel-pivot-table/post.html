엑셀 함수로도 되지만 수식이 복잡해지는 순간 피벗테이블이 필요합니다. "지역별 매출", "월별 건수"처럼 데이터를 요약할 때 드래그 몇 번으로 끝나는 기능입니다.

피벗테이블이 뭔가요

원본 데이터를 그대로 두고, 보고 싶은 기준으로 다시 요약해 보여주는 기능입니다. 행·열·값을 지정하면 표가 자동으로 만들어집니다. 수식을 일일이 쓰는 것보다 훨씬 빠르고 실수도 적습니다.

만드는 순서

데이터 범위를 선택하고 삽입 탭에서 피벗테이블을 누르면 됩니다. 오른쪽에 필드 목록이 나오면 행·열·값·필터 영역에 원하는 항목을 끌어다 놓으세요.

1. 데이터 표 전체 선택 (Ctrl+A)
2. 삽입 탭 → 피벗테이블
3. 행: 지역 / 열: 월 / 값: 매출 합계
4. 필터: 연도 등 필요하면 추가

자주 쓰는 설정

설정쓰는 경우
값 필드 합계매출·건수·금액 합산
값 필드 평균평균 단가·평균 점수
값 필드 개수항목별 건수 파악
필터특정 연도·부서만 보기

실전 예시

판매 데이터에서 "지역별·월별 매출"을 보고 싶다면 행에 지역, 열에 월, 값에 매출 합계를 넣으면 됩니다. "어느 지역이 잘 팔리는지", "몇 월에 피크인지"가 한눈에 보입니다.

주의할 점

  • 원본 데이터가 바뀌면 피벗테이블도 새로고침해야 합니다 — 데이터 탭에서 새로 고침
  • 빈 셀이나 합계 행이 있으면 결과가 어긋날 수 있습니다
  • 날짜는 연·월·일로 그룹화해서 쓰면 보기 편합니다

정리

피벗테이블은 "데이터 요약의 지름길"입니다. 함수로 하나하나 계산하기 전에 피벗테이블로 먼저 확인해 보세요. 10분이면 감이 옵니다.
