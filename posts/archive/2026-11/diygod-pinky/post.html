문제 제기

AI 에이전트에게 폰으로 확인해달라고 시키고 싶은데, 막상 폰을 만질 수 있는 에이전트는 드뭅니다. pinky가 그 간극을 메웁니다.

무엇인가

AI 에이전트가 실제 iPhone이나 Android 폰을 대신 조작하게 해주는 MCP 게이트웨이 앱입니다. 위험한 동작은 반드시 사람 승인을 거칩니다. 현재 GitHub 스타 1,811개, 주 언어는 Go입니다.

핵심 기능

  • MCP로 Claude Code·Codex·Cursor 등 에이전트 연결
  • 결제·전송·삭제 등 위험 동작은 사용자 클릭 승인
  • 뱅킹·비밀번호 앱과 비밀번호 필드는 기본 차단
  • macOS·Windows·Linux 데스크톱 앱

설치와 첫 실행

GitHub Releases에서 OS에 맞는 설치 파일을 받습니다. Mac은 dmg를 Applications에 드래그하거나 brew install --cask diygod/tap/pinky, Windows는 pinky-setup 실행 파일, Linux는 deb 또는 tar.gz를 씁니다.

brew install --cask diygod/tap/pinky

기본 사용법

폰을 USB로 연결하고 Settings › Agents에서 Claude Code·Codex·Cursor 같은 에이전트에 Pinky MCP를 연결합니다. 이후 에이전트에게 폰 작업을 시키면 Pinky 창에서 진행 상황이 보이고, 결제·삭제 같은 위험 동작은 직접 승인합니다.

git clone https://github.com/DIYgod/pinky.git

추천 이유

  • 승인이 프롬프트가 아니라 게이트웨이에서 강제되는 구조
  • 오프리밋 기본값과 세밀한 안전 규칙

누구에게 필요한가
