Ollama로 모델을 몇 개 받다 보면 "용량이 꽤 차는데 어디에 저장되지?" 궁금해집니다. 모델이 GB 단위라 디스크를 많이 먹거든요. 다운로드부터 용량 확인, 정리까지 실무 명령어를 정리했습니다.

모델은 어디에 저장되나요

Ollama 모델은 기본적으로 사용자 홈 디렉터리의 .ollama/models에 저장됩니다. Windows라면 C:\Users\사용자명\.ollama\models입니다.

저장 위치를 바꾸고 싶으면 환경 변수 OLLAMA_MODELS로 다른 드라이브를 지정할 수 있습니다.

설치된 모델과 용량 확인

가장 기본적인 확인 명령입니다.

ollama list      # 설치된 모델 목록 + 크기
ollama ps        # 지금 실행 중인 모델

모델 크기는 파라미터 수와 양자화 수준에 따라 결정됩니다. 같은 모델이라도 Q4 같은 양자화 버전이 가장 가볍고, FP16은 원본에 가깝지만 훨씬 큽니다.

용량을 줄이는 팁

  • 필요한 모델만 받기 — ollama pull로 필요한 것만 다운로드
  • 태그로 크기 선택 — qwen3:4b처럼 작은 변형을 고르면 용량이 확 줄어듭니다
  • 안 쓰는 모델 삭제 — ollama rm 모델명
  • 실행 중인 모델은 메모리를 씁니다 — ollama ps로 확인 후 필요 없으면 종료

모델 정리 명령어

# 안 쓰는 모델 삭제
ollama rm qwen3:7b

# 전체 목록에서 이름 확인 후 삭제
ollama list
ollama rm <모델명>

실수로 지웠다면 ollama pull로 다시 받을 수 있습니다. 다만 수 GB 다운로드라 시간이 걸립니다.

활용 팁 — 자주 쓰는 모델만 남기기

용량 관리의 핵심은 "자주 쓰는 모델"과 "테스트용 모델"을 구분하는 것입니다.

  • 메인으로 쓸 모델 1~2개만 상시 유지
  • 새 모델 테스트 후 안 쓰면 바로 삭제
  • API로 연결할 때는 작은 모델(7B 이하)이 현실적

정리

Ollama 모델은 ollama list로 확인하고 ollama rm으로 정리합니다. 저장 위치는 .ollama/models이며, 용량이 부담되면 작은 태그(4b·7b)를 고르세요.
