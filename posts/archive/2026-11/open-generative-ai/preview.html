셀프호스팅 이미지·영상 생성 스튜디오

#이미지생성#영상생성#셀프호스팅#오픈소스#Docker#Wan2GP#립싱크#생성AI#로컬모델#MIT

AI 이미지·영상 생성 도구가 넘쳐나도 정작 필요한 건 "한 곳에서 다 되는 것"입니다. 이미지 생성기는 따로, 영상 생성기는 따로, 립싱크는 또 따로 — 구독료도 제각각이죠.

Open-Generative-AI는 이미지·영상·오디오·립싱크를 14개 스튜디오로 묶은 셀프 호스팅 스튜디오 앱입니다. GitHub 별 3.3만 개, MIT 라이선스입니다. 핵심은 콘텐츠 필터 없이 쓸 수 있다는 점과, 클라우드 모델과 로컬 모델을 한 UI에서 오갈 수 있다는 점입니다.

Open-Generative-AI는 무엇인가

README의 표현 그대로 "콘텐츠 필터 없는 오픈소스 AI 이미지·영상 플랫폼 대안"입니다. 텍스트→이미지, 이미지→이미지, 텍스트→영상, 이미지→영상, 오디오 기반 립싱크까지 지원합니다.

14개 스튜디오로 나뉩니다: Image, Video, Audio, Lip Sync, Cinema, Workflows, AI Clipping, Vibe Motion, Marketing, Agents, Design Agent, Apps, MCP & CLI.

"No content filters, no prompt rejections, no guardrails"가 셀링 포인트입니다. 창작 자유를 앞세운 만큼, 생성물의 책임은 사용자에게 있습니다.

중요한 전제 하나: 클라우드 모델 호출은 MuAPI라는 호스티드 서비스가 처리합니다. 즉 "오픈소스"는 프론트엔드와 워크플로 UI이고, 클라우드 생성은 MuAPI 계정/크레딧이 필요합니다. 완전 무료·무제한 생성이 아닙니다.

설치: 데스크톱 앱이 가장 간단하다

v2.0.0부터 원클릭 데스크톱 앱이 있습니다. Node.js 없이 바로 설치됩니다.

플랫폼설치 파일
macOS (Apple Silicon)arm64.dmg
macOS (Intel)x64.dmg
WindowsSetup.exe (SmartScreen 경고 가능)
LinuxAppImage / .deb

macOS는 공증이 안 돼 있어서 첫 실행 시 xattr -cr로 게이트키퍼를 우회해야 합니다. Windows는 SmartScreen "추가 정보 → 실행"으로 진행합니다. 설치 없이 브라우저로 쓰는 호스티드 버전도 있습니다.

로컬 모델: 두 개의 엔진

데스크톱 앱의 진짜 강점은 로컬 추론 엔진이 두 개 내장됐다는 점입니다.

엔진방식용도
sd.cpp앱이 자동 다운로드, 별도 설치 불필요이미지 모델 (Flux, Qwen-Image 등)
Wan2GP직접 설치, CUDA/ROCm GPU 필요영상 모델 (Wan 2.1/2.2, LTX-2 등)

설정은 Settings → Local Models에서 하고, 각 스튜디오의 모델 선택 옆에 ⚡ Local 토글을 켜면 로컬로 생성됩니다. 로컬 생성은 API 키가 필요 없습니다.

클라우드 모델 연결

로컬이 안 되는 작업이나 더 큰 모델이 필요하면 MuAPI 경유 클라우드 모델을 씁니다. 지원 모델군이 넓습니다.

  • 이미지: Flux, Nano Banana, Seedream 등
  • 영상: Kling, Sora, Veo, Wan 2.2 등
  • 립싱크: Infinite Talk, LTX Lipsync 등

"Powered by MuAPI"라는 표기가 모든 페이지에 있으니, 클라우드 생성 시 계정과 크레딧이 필요하다는 걸 인지하고 쓰면 됩니다. 화이트라벨($49/월~)까지 제공해서, 이 앱을 자기 브랜드로 재판매하는 것도 가능합니다.

자원과 비용 계산

로컬 추론은 결국 GPU가 답입니다.

  • sd.cpp 이미지 — 멀티 GB 가중치, GPU VRAM 8GB+ 권장
  • Wan2GP 영상 — 더 큰 VRAM, NVIDIA/AMD CUDA·ROCm 필수
  • 클라우드 — GPU 없이 되지만 생성당 크레딧 차감

앱 자체는 가볍지만 로컬 모델 가중치는 수 GB~수십 GB입니다. OPEN_GENERATIVE_AI_LOCAL_AI_DIR 환경변수로 모델 저장 위치를 다른 드라이브로 옮길 수 있습니다.

제작 워크플로 예시

14개 스튜디오가 각각 독립적이지만, 실제 사용은 조합입니다.

  1. Image Studio에서 컨셉 이미지 생성
  2. Video Studio에서 이미지→영상 애니메이션
  3. Lip Sync Studio에서 나레이션 동기화
  4. Cinema Studio에서 최종 편집·합성

Workflows와 Agents 스튜디오가 이 과정을 템플릿화·자동화하는 역할을 합니다. MCP & CLI 지원도 있어서 외부 도구와 연동 가능합니다.

MCP와 CLI로 외부 연동

14개 스튜디오 중 하나가 MCP & CLI입니다. 생성 기능을 외부 에이전트나 스크립트에서 호출할 수 있게 열어둔 통로입니다.

예를 들어 콘텐츠 파이프라인에서 "이 브리프로 이미지 4장 생성 → 영상 변환 → 립싱크"를 자동화하고 싶다면, MCP를 통해 다른 도구에서 이 스튜디오를 호출할 수 있습니다. 수동 클릭 중심의 UI지만, 자동화 경로도 마련돼 있다는 뜻입니다.

누구에게 맞나

콘텐츠 제작을 직접 하는 프리랜서·소규모 팀, 여러 생성 모델을 한 화면에서 비교하고 싶은 사람, 로컬 GPU가 있어 API 비용 없이 돌리고 싶은 사람에게 맞습니다.

반대로 "완전 무료로 무제한 생성"을 기대하면 안 됩니다. 로컬은 GPU가 필요하고, 클라우드는 MuAPI 크레딧이 듭니다. 필터가 없다는 건 자유이자 책임이기도 합니다.

한계와 주의

  • MuAPI 의존 — 클라우드 생성은 MuAPI 계정이 필요하고, 완전 무료가 아닙니다
  • GPU 요구 — 로컬 모델은 고사양 GPU 없이는 사실상 불가
  • 필터 없음 — 콘텐츠 제한이 없으므로 법적·윤리적 책임은 사용자에게 있습니다
  • 성숙도 — 데스크톱 앱이 v2.0으로 갓 나온 단계라 안정성은 지켜봐야 합니다
  • macOS 공증 — Gatekeeper 우회가 필요해 기업 배포엔 번거로울 수 있습니다

정리

Open-Generative-AI는 "생성 AI 스튜디오를 한 앱에"라는 목표에 가장 근접한 오픈소스입니다. 14개 스튜디오, 로컬+클라우드 이중 엔진, 필터 없는 자유 — 셋 다 실제로 구현돼 있습니다. 다만 클라우드 모델이 MuAPI에 묶여 있고 로컬은 GPU가 필요하다는 현실을 알고 쓰면, 콘텐츠 제작 파이프라인의 강력한 허브가 됩니다.
