문제 제기

Claude Code를 비싼 로컬 머신이 아니라 서버에서 돌리고 싶을 때, 도구 실행 위치 때문에 고민이 생깁니다. cc-remote는 그 역할을 나눠주는 도구입니다.

무엇인가

Claude Code를 SSH로 접속한 서버에서 실행하고 도구 호출은 내 머신에서 실행하는 ACP 에이전트입니다. 서버에는 로그인과 구독만 있으면 됩니다. 현재 GitHub 스타 376개, 주 언어는 TypeScript입니다.

핵심 기능

  • 모델·로그인·구독은 서버에 유지
  • 코드·셸·툴체인·에디터는 내 머신에 유지
  • Zed·paseo 등 ACP 클라이언트에 바로 연결
  • 서버에 데몬이나 별도 설치 없이 ssh만으로 동작

설치와 첫 실행

로컬 머신에는 Bun만 있으면 됩니다. 클론 후 의존성을 설치하고 컴파일하면 cc-remote 바이너리가 PATH에 올라갑니다.

git clone https://github.com/AkaraChen/cc-remote && cd cc-remote
bun install
bun run compile
bun link

기본 사용법

~/.config/cc-remote/host에 SSH로 접속할 서버를 적고 cc-remote doctor로 연결을 확인합니다. ACP 클라이언트(Zed·paseo·acpc)에는 cc-remote를 에이전트로 등록하면 서버의 Claude Code가 로컬 도구와 함께 동작합니다.

mkdir -p ~/.config/cc-remote && echo  > ~/.config/cc-remote/host
cc-remote doctor

추천 이유

  • 서버는 claude가 있으면 끝이라 구축이 간단
  • 세션·권한·모드 등 진짜 Claude Code 동작 유지
  • 로컬은 단일 바이너리 하나
  • 라이선스 표기가 없어 사용 전 확인 필요

누구에게 필요한가

로컬에 Claude Code를 설치하지 않고 원격으로 쓰려는 개발자에게 특히 유용합니다.

정리

cc-remote는 Claude Code를 SSH로 접속한 서버에서 실행하고 도구 호출은 내 머신에서 실행하는 ACP 에이전트입니다. 서버에는 로그인과 구독만 있으면 됩니다.입니다. 작은 작업 하나부터 붙여 보는 것을 권합니다.
