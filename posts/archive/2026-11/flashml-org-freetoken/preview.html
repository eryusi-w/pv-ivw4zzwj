CPU·GPU로 MoE 모델을 서빙하는 엔진 (FreeToken)

#AI도구#오픈소스#FreeToken#모델AI인프라#생산성#자동화#개발도구#업무효율#CPUGPU협업을통한대역폭적응형실행#전역LRU기반전문가캐시와이중버퍼링프리필스트리밍

MoE 모델을 로컬에서 돌리면 GPU 메모리가 부족해 포기하기 쉽습니다. FreeToken은 CPU와 GPU를 함께 써서 이런 모델을 개인 하드웨어에서도 빠르게 서빙하는 엔진입니다.

Mixture-of-Experts 모델을 엣지 하드웨어에서 실시간으로 실행하는 서빙 엔진으로, Apache-2.0 라이선스에 현재 GitHub 스타 16,720개입니다.

핵심 특징 3가지

  • CPU·GPU 협업 — 대역폭에 맞춰 작업을 나눠 VRAM 부담을 줄입니다.
  • 전문가 캐시 — 자주 쓰는 전문가를 메모리에 유지하고 이중 버퍼링으로 프리필을 빠르게 합니다.
  • 동적 VRAM 재할당 — 엔진 재시작 없이 메모리를 재조정합니다.

설치와 빠른 실행

pip install freetoken

설치 후 모델 경로와 사용할 디바이스(CPU/GPU 비율)를 설정해 서빙을 시작합니다. OpenAI 호환 API 형태로 붙는지 README에서 확인합니다.

실전 활용 시나리오

큰 모델부터가 아니라, 가진 하드웨어에서 돌아가는 크기의 MoE 모델로 시작합니다.

git clone https://github.com/FlashML-org/FreeToken.git
  • 1단계 — pip로 설치하고 지원 모델 목록을 확인합니다.
  • 2단계 — VRAM 용량에 맞는 MoE 모델을 골라 설정합니다.
  • 3단계 — 샘플 요청으로 토큰 생성 속도를 측정합니다.
  • 4단계 — 캐시·버퍼링 옵션을 조정해 속도를 비교합니다.

직접 쓰기 전 알면 좋은 점

그래도 대규모 모델은 GPU 메모리 요구량이 높습니다. CPU 협업이 있긴 하지만 속도는 순수 GPU 서빙보다 느릴 수 있고, 지원 모델 목록이 계속 바뀌니 최신 README 기준으로 확인이 필요합니다.

누구에게 필요한가

AI 연구원·ML 엔지니어·대규모 모델 운영자에게 특히 유용합니다. 데이터센터 없이 로컬에서 MoE 모델을 실시간으로 실험하고 싶은 경우에 맞습니다.

정리

MoE 모델의 약점인 메모리 병목을 CPU 협업과 캐싱으로 푸는 서빙 엔진입니다. 내 하드웨어에서 돌아가는 크기부터 정해 시작하면 실패 확률이 낮습니다.
