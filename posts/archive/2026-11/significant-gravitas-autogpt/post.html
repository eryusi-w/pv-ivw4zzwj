"이거 알아서 해줘"라고 말했는데 에이전트가 계획 없이 돌아다니기만 하면 실무에서는 못 씁니다. AutoGPT는 목표를 주면 스스로 계획하고 실행하는 자율 에이전트 프레임워크입니다.

LLM 기반 자율 에이전트를 만들고 실행할 수 있는 프레임워크로, OpenAI·Claude·Llama 등 다양한 모델과 연동되며 현재 GitHub 스타 187,822개입니다.

핵심 특징 3가지

  • 목표 기반 계획 — 자연어 목표를 받아 작업 단위로 나눠 계획을 세웁니다.
  • 자동 실행·피드백 — 결과를 보고 다음 단계를 스스로 조정합니다.
  • 플러그인 확장 — 다양한 LLM과 API를 플러그인으로 연결합니다.

설치와 빠른 실행

pip install -e .

저장소를 클론해 개발 모드로 설치하는 방식입니다. 사용할 LLM의 API 키를 설정 파일에 넣고, 목표를 자연어로 입력해 실행합니다.

실전 활용 시나리오

자율 실행의 범위가 넓은 만큼, 처음에는 읽기·정리 같은 되돌리기 쉬운 목표로 시작합니다.

git clone https://github.com/Significant-Gravitas/AutoGPT.git
  • 1단계 — 저장소를 클론하고 의존성을 설치합니다.
  • 2단계 — 사용할 LLM의 API 키를 설정 파일에 등록합니다.
  • 3단계 — "이 폴더의 문서를 요약해 줘"처럼 범위가 좁은 목표를 입력합니다.
  • 4단계 — 계획과 실행 로그를 보며 목표를 점차 구체화합니다.

직접 쓰기 전 알면 좋은 점

라이선스가 부분별로 다릅니다. autogpt_platform 폴더는 PolyForm Shield 라이선스라 상용 서비스에 제약이 있을 수 있으니, 플랫폼을 제품에 포함할 계획이라면 라이선스 조항을 먼저 확인하세요. 자율 실행이므로 API 비용도 목표가 복잡할수록 커집니다.

누구에게 필요한가

LLM 기반 에이전트를 개발하거나 연구하는 개발자·연구자에게 특히 유용합니다. 목표만 주고 에이전트가 계획부터 실행까지 하게 하는 방식을 실험해 보고 싶은 경우에 맞습니다.

정리

목표를 말하면 스스로 계획하고 실행하는 자율 에이전트의 원조 격 프레임워크입니다. 범위가 넓은 만큼 작은 목표부터 검증하며 쓰는 게 안전합니다.
