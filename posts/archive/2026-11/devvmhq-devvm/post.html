문제 제기

코딩 에이전트가 내 머신에서 마음껏 명령을 실행하면, 프로젝트가 꼬였을 때 되돌리기가 어렵습니다. devvm은 프로젝트별 격리 VM으로 이 불안을 줄입니다.

무엇인가

프로젝트마다 격리된 VM 샌드박스를 만들어 코딩 에이전트가 안전하게 실행되게 하는 도구입니다. 툴체인이 포함된 환경을 바로 제공합니다. 현재 GitHub 스타 552개, 주 언어는 Go입니다.

핵심 기능

  • 프로젝트별 독립 VM 환경
  • 프로젝트에 필요한 툴체인 포함
  • devvm doctor로 실행 환경 사전 점검
  • macOS Homebrew와 Linux 설치 스크립트 제공

설치와 첫 실행

curl -fsSL https://github.com/devvmhq/devvm/releases/latest/download/install.sh | bash

git clone https://github.com/devvmhq/devvm.git

클론 후 저장소의 안내에 따라 실행합니다.

devvm는 프로젝트마다 격리된 VM 샌드박스를 만들어 코딩 에이전트가 안전하게 실행되게 하는 도구입니다. 툴체인이 포함된 환경을 바로 제공합니다.입니다. 작은 작업 하나부터 붙여 보는 것을 권합니다.
