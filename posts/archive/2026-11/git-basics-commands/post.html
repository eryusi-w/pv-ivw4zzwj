개발을 시작하면 가장 먼저 만나는 도구가 Git입니다. "깃이 뭐예요?"부터 "커밋이 뭐예요?"까지, 처음엔 용어가 낯설지만 실제로 쓰는 명령어는 몇 개 없습니다. 초보가 꼭 알아야 할 10개만 정리했습니다.

Git이 뭔가요

Git은 파일의 변경 이력을 저장하는 버전 관리 도구입니다. "이전 버전으로 돌아가기", "누가 뭘 바꿨는지 보기", "여러 사람이 동시에 작업하기"가 가능해집니다. 깃허브(GitHub)는 이 저장소를 인터넷에 올려 공유하는 서비스입니다.

처음 시작할 때

프로젝트 폴더에서 Git을 시작하거나, 이미 있는 저장소를 내려받습니다.

git init                    새 프로젝트 시작
git clone https://github.com/user/repo.git   기존 저장소 내려받기

매일 쓰는 5개

수정 → 확인 → 저장 → 올리기의 흐름입니다.

git status                  뭐가 바뀌었는지 확인
git add 파일명               변경 내용을 스테이징에 올리기
git commit -m "메시지"        변경을 저장소에 기록
git push                     내 컴퓨터 → 원격 저장소로 업로드
git pull                     원격 저장소 → 내 컴퓨터로 다운로드

브랜치와 되돌리기

브랜치는 "작업 복사본"입니다. 기능을 실험할 때 main을 건드리지 않고 따로 작업할 수 있습니다.

git branch                  브랜치 목록 보기
git switch -c 새기능          새 브랜치 만들고 이동
git log --oneline            커밋 기록 보기
git checkout 커밋해시          특정 시점으로 되돌리기

자주 하는 실수

  • add 없이 commit만 하는 것 — commit 전에 반드시 add
  • push 전에 pull을 안 하는 것 — 충돌이 생길 수 있습니다
  • 비밀번호·API 키를 commit에 넣는 것 — .gitignore에 먼저 등록

정리

Git은 처음엔 복잡해 보이지만, init→add→commit→push 네 가지만 반복하면 됩니다. 나머지는 필요할 때 배우면 됩니다.

참고: Git 공식 문서(git-scm.com) 기준 일반적인 사용법입니다.
