엑셀 VLOOKUP·INDEX-MATCH 오류 0건, ChatGPT로 1분 만에 자동 작성하는 실전 프롬프트

복잡한 엑셀 함수 수식을 자연어로 설명만 하면 ChatGPT가 즉시 오류 없는 수식과 VBA 매크로를 생성해주는 초간단 자동화 비법을 공개합니다.

🎯 대상 독자

매일 엑셀 데이터 매칭과 정리로 스트레스를 받는 직장인 및 데이터 분석 입문자

✨ 핵심 실무 특징
  • VLOOKUP, XLOOKUP, INDEX-MATCH 등 복합 함수의 논리적 오류를 AI가 사전 검증하여 정확도 극대화
  • 단순 수식 생성을 넘어 조건부 서식 규칙 및 반복 업무용 VBA 매크로 코드까지 원스톱 생성
  • 엑셀 문법을 몰라도 '데이터 구조'와 '목표 결과'만 설명하면 즉시 적용 가능한 수식 반환
🚀 3단계 실천 가이드
  1. 1단계: 엑셀 시트의 열 이름(헤더)과 데이터 개수, 매칭 기준 열을 명확히 정의하여 텍스트로 정리
  2. 2단계: 'A열의 ID를 기준으로 B열의 이름을 가져오되, 없으면 #N/A 대신 '미등록'으로 표시해줘'와 같이 자연어 프롬프트 입력
  3. 3단계: 생성된 수식을 복사하여 엑셀에 붙여넣고, 예외 데이터 3~5건으로 정상 동작 여부를 최종 검증
💡 실전 팁 / 프롬프트 / 설정
프롬프트 예시: "다음 엑셀 데이터 구조를 가정해줘. Sheet1의 A열은 '사원ID', B열은 '이름'이고, Sheet2의 A열은 '사원ID', B열은 '부서명'이다. Sheet1의 C열에 A열의 사원ID를 기준으로 Sheet2에서 부서명을 가져오는 VLOOKUP 수식을 작성해줘. 만약 ID가 없으면 '정보 없음'으로 표시되도록 해줘."
